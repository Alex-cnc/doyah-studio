## 3. 插件模型（设计核心）

**3.1 清单（manifest）** —— 每个插件一份声明，字段即契约：

| 字段 | 含义 | 约束 |
|---|---|---|
| `id` / `displayName` / `version` | 身份与版本 | `id` 全局唯一；版本用于诊断行 |
| `apiVersion` | 宿主 API 版本 | 不匹配 ⇒ **降级该插件**（不崩、不静默） |
| `capability` | 所需能力位（工作区 / 数据库 / 笔记…） | **只声明、不新增**；判据仍只在 `LicensePresentation`（§3.24 不变） |
| `contributions` | 挂点声明（见 §5） | 挂点顺序 = **声明顺序**（唯一来源） |
| `storage` | 存储归属：`pluginOwned` / `hostManaged` | 默认 `pluginOwned`（沿用 `FR-PLUG-04` 数据家独立） |
| `dependencies` | 依赖的其它插件 / 宿主能力 | 仅声明，本轮不做版本求解 |

**3.2 生命周期**：`discovered → loaded → activated → deactivated → unloaded`
—— 激活失败**只降级自己**，宿主照常启动；每一步写一行诊断（`startup.log`）。

**3.3 降级语义（硬性）**：插件不在 / 未授权 / `apiVersion` 不匹配 ⇒ 其挂点项**整体不出现**，且**启动无错误输出**（不是灰掉、不是画的时候跳过）。

**3.4 依赖方向（沿用 §3.23 单向复用）**：宿主 → 插件只传**文本与标识**（当前连接、库/表、选中 SQL），**不传结果行数据**；插件**不得**依赖宿主的数据库 / 工作区类型。

## 4. 宿主侧装配器

1. **注册表**：`PluginRegistry` —— 扫描内置插件目录（`Plugins/<id>/`）得清单，静态注册（无动态加载）；
2. **装配顺序**：按清单声明顺序；同挂点内按 `order` 字段，缺省 = 声明顺序；
3. **失败隔离**：单个插件 `load/activate` 抛错 ⇒ 记诊断 + 跳过，**不影响其它插件与宿主**；
4. **诊断**：启动时一行汇总 `插件：<已激活列表> / <降级列表（原因）>`（与许可证那行同款，排障用）；
5. **不变量**：宿主**不得**出现 `if pluginX` 式的功能分支 —— 所有可见性/可达性**只有一处判据**（同 §3.24 第 5、6 条的风格）。

## 5. 挂点契约（contribution points）

| 挂点 | 用途 | 本轮落点 |
|---|---|---|
| `activityBar` | 活动栏一项（笔记 = 一栏，非浮层） | 笔记、回放 |
| `mainPaneTab` | 主区页签 | 回放（或笔记的预览面） |
| `menu` | 菜单项（「显示」等） | 笔记、回放 |
| `settings` | 设置页一节 | 笔记存储位置 |
| `searchIndex` | 索引贡献（可搜索） | 笔记 |
| `statusBar` | 状态栏小件 | 回放 |
| `commandPalette` | 命令 | 笔记、回放 |

**规则**：挂点只声明**位置与形态**；**"谁能看见"由宿主按能力位裁决**（不在插件里判许可）。

## 6. 存储与数据边界

- **默认 `pluginOwned`**：数据落插件自己的数据家（笔记库 `<App Support>/DoyahNotes/`，与工程数据家**平级** —— `FR-PLUG-04` 已落地并验证）；
- **`hostManaged` 例外**：仅当插件明确要求宿主代管（本轮**无**用例），须在清单声明并在门禁里例外登记；
- **迁移**：既有一次性迁移（`NoteStoreMigration`）保持不变；插件化**不改字节位置**（避免二次搬迁风险）；
- **Linux / 离线**：笔记插件在三端装配，Linux 走本地 SQLite + **进程内零网络出口**（`check-notes-offline.py` 保持绿）。

## 8. 验收判据（可机械复跑）

1. **骨架三探针**：① 装 ⇒ 挂点出现；② 卸 ⇒ 挂点消失；③ 不在 ⇒ 挂点消失且**启动零错误**（`rc=0`，无 error 行）；
2. **门禁（扩）**：`check-plugin-assembly.py` 增断言 —— 清单字段齐 · **无 IPC**（`NSXPC`/`xpc_` 命中 0）· **许可判据唯一**（`LicensePresentation` 之外无能力位判断）· **挂点唯一来源**（无 `if pluginX` 式分支）；
3. **隔离**：插件目录外**零引用**插件内部类型（`grep` 读数 = 0）；
4. **仓库口径**：`swift build`（Xcode 工具链）⇒ `Build complete!`；`verify-all.sh` 18 项绿；
5. **打包**：产物含插件目录与清单（与 `FR-PLUG-01` 既有打包断言同源）；Linux 离线判据保持绿。
