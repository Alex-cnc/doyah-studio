1. **既有高亮沿用字节偏移**：`sql::tokenize` 的 `start`/`end` 是**字节**，而前端 `highlightPieces` 拿它当

   `DatabaseView.vue` 放到 `platform/`、判据文件在 `Platform/` ⇒ 相对 import 全断）。
   结论：统一改名的方向 = **小写 → 大写 `Platform/`**（与盘上真名、与 macOS/linux 一致）；这动作单独一轮做
   （机械 rename + `git ls-files` 复核 + 全绿复跑），不在收尾时动。
