- Rust：版本感知列名（12 vs 13 vs 18）、三种排序、过滤自身、limit 夹取、字符截断（中文不被切坏）、
  排序名解析、指引三条齐全。
- 前端：挂载真组件 —— ① 可用时列出排行行且排序切换会重取；② 不可用时**出现三步指引且没有排行表**；
  ③ 失败时给可读原因（不是静默空表）。
- 自证：注入四处（列名不按版本 / 去掉自身过滤 / 不可用也发排行 / 截断按字节）必须各自转红。

### 结果

**做了两条**（`FR-DIAG-03` 端到端 + 顺手修掉管理面板一个**真缺陷**）。

**① `FR-DIAG-03` 慢查询排行（逻辑 → IPC → 可见入口 → 判据）**
- 领域层 `Db/src/slow_query.rs`（新，12 项单测）：
  - `SlowQuerySort`（`total` / `mean` / `calls`，认中文与驼峰；认不出返回 `None`，不静默取默认）；
  - **列名按服务端主版本**：PG ≥13 → `total_exec_time` / `mean_exec_time`，12 及更早 → `total_time` / `mean_time`
    （版本串 `18.6` / `13.4 (Debian …)` / `PostgreSQL 12.9 on …` 都认；认不出按 0 走老口径）；
  - 排行 SQL 过滤扩展自身（`query NOT ILIKE '%pg_stat_statements%'`）+ **并列按 calls 兜底**（顺序确定）；
  - `clamp_limit`（0 → 默认 20，超 200 夹到 200 —— `LIMIT 0` 会被界面读成「没有慢查询」）；
  - `truncate_query` 按**字符**截断（上界 200 字符，截断加 `…` 并置 `truncated`）；
  - 可用性一问三答（`installed` / `available` / `preloaded`）+ **三种情形分开说**的可读原因 + 三步指引
