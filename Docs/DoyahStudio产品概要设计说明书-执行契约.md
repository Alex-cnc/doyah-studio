## 1. 设计范围与边界

### 1.1 本设计是什么

覆盖 Studio 线 5 类能力，逐类写成可判定条款：

1. **工作区**：文件树与文件生命周期（新建 / 改名 / 删除 / 打开识别 / 外部改动监听 / 工作区切换）、编辑器（编辑动作、撤销粒度、查找替换、跳转、诊断、格式化、折叠、多光标、大文件承载）、页签与会话恢复、全局搜索与命令面板、下方面板（问题 / 输出 / 终端 / 调试）、Git 只读与差异、内嵌浏览器与 Markdown 预览、撤销。
2. **数据库**：连接（新建 / 校验 / 编辑 / 删除 / 保活 / URL 导入导出 / 组织）、凭据、SSH 隧道、表格与对象树、元数据列举、单次与多语句执行、事务、高危确认、中断、结果集（展示 / 排序筛选 / 大结果 / 多结果集 / 导出）、行编辑、表设计与脚本生成、导入、执行计划与统计读数、锁与等待、查询历史、服务器会话与权限、任务定义与审批与执行回执、方言差异与驱动接入。
3. **智能助理接入**：对话页签（消息流、流式渲染、工具调用卡片、内联审批、差异块）、工作区编辑区的 AI 辅助、许愿式编程入口；宿主向助理单向传上下文。
4. **授权**：能力位解析（开发工作区 / 智能数据库助理 / 笔记）、按能力位呈现入口、到期降级但绝不锁数据、设备配额。
5. **横切工程**：声明式工程描述与可重复生成、命令行出口、插件同进程装配、随代码同步的文档三边一致。

必须实现的组件、接口、数据对象：§3 / §4 / §5 全部条目，一条不多一条不少。

### 1.2 本设计不是什么

- 不是详细设计：窗口模型、控件尺寸、文件落点、具体类型名 → 各端实现要点文件。
- 不含 Notes 与复盘两域任何条款 → 产品级契约与各自实现要点。
- 不含测试读数、门禁结果、真库读数 → 验收台账（机器生成）；本书只写判据与命令。
- 不含状态与进度 → 开发计划书（状态只有一处）。
- 不引入：消息队列、独立后端服务、多租户、云数据库代理、第二套文案/令牌真源。
- 不实现：Git 写操作（提交 / 推送 / 合并 / 切分支）、移动端布局适配、管理后台页面、未登记的新入口。
- 不改变「要什么」：本书任何条款不得新增需求书没有的行为。

### 1.3 边界与判据

| 边界项 | 允许 | 禁止 | 判定依据 |
|---|---|---|---|
| 功能边界 | 需求书 `FR-STD-*` 已列的能力 | 新增未登记能力（含「顺手」优化） | `Scripts/check-req-ids.py`；新能力必须先有 FR |
| 技术边界 | 平台中立层只用跨平台 API；界面层只能经能力层拿值类型 | 平台中立层 import 界面框架；界面层持有连接 / 事务 / 文件句柄 | `check-core-portability.py`、`check-platform-neutrality.py` |

| 调用边界 | 界面 → 装配 → 能力 → 驱动 | 界面直调能力层；能力层回调界面；插件反向依赖装配 | `check-note-module-isolation.py`；跨层只传值 |
| 界面边界 | 已登记页签与命令 | 新增未登记入口/路由；引入新界面库替代既有控件 | `check-palette-wiring.py`、`check-design-tokens.py` |
| 版本边界 | 契约改动五步齐全（§13） | 改正文不升版本；升版本不改变更记录 | `check-doc-versions.py` |

## 2. Agent 执行总则

1. 只实现本书与需求书明确要求的内容；不做任何「顺手优化」。
2. 新增依赖必须先出现在 §11 允许清单；未列出即不得引入（含语言包、系统命令、脚本工具）。
3. 每个接口必须实现四类行为：成功、失败、非法输入、**禁止兜底**（§4）。
4. 状态变化必须符合 §6；不得新增状态或流转。
5. 错误必须按 §9 返回；禁止用空对象、默认值、静默成功掩盖失败。
6. 每个页面/视图必须实现 §8.4 六态；缺一即缺陷。
7. 遇到信息不足或规则冲突：停止实现，输出 `BLOCKED` + 阻塞点 + 上游条款 + 待确认问题。
8. 完成实现后逐条自检 §12 与 §8.10，并输出每条判据的通过/不通过与证据。

## 4. 接口契约

> 每个接口写清：请求、成功响应、失败响应、非法输入、禁止行为。行为锚不上 `FR-STD-*` 的属实现偏好，不得写进本节。

### 4.1 连接建立与校验

对应需求：`FR-STD-DB-CONN-001`、`FR-STD-DB-CONN-002`

- 用途：按连接配置建立会话并暴露连接句柄。调用方：连接管理。实现方：驱动与方言。
- 请求参数：

| 参数 | 类型 | 必填 | 校验规则 | 说明 |
|---|---|---|---|---|
| 名称 | 文本 | 是 | 非空、同一工作区内唯一 | 显示名 |
| 数据库类型 | 枚举 | 是 | 取值为已接入类型 | 决定默认端口与 SSL 默认值 |
| 主机 | 文本 | 是 | 非空 | 主机名或地址 |
| 端口 | 整数 | 是 | 1–65535，先解析再校验 | 类型切换时联动默认值 |
| 数据库名 | 文本 | 是 | 非空 | 目标库 |
| 用户名 | 文本 | 是 | 非空 | 角色名 |
| 凭据引用 | 标识 | 是 | 指向密钥存储内的口令条目 | 口令本体不进请求体 |
| SSL 模式 | 枚举 | 是 | 取值为该类型支持的集合 | 默认值随类型变化 |
| 超时 | 整数 | 是 | > 0 | 单位秒 |

- 成功响应：连接句柄 + 生效的类型与库名 + 建立耗时。
- 失败响应：

| 场景 | 错误码 | Body | 禁止行为 |
|---|---|---|---|
| 参数非法 | `CONN_INVALID_CONFIG` | 字段级原因列表 | 禁止返回成功再在首条语句时报错 |
| 凭据缺失/不可解 | `CONN_NO_CREDENTIAL` | 缺哪一条 + 下一步 | 禁止用空口令尝试连接 |
| 主机不可达/超时 | `CONN_UNREACHABLE` | 原话 + 主机与端口 | 禁止静默降级为「离线模式」 |
| 认证失败 | `CONN_AUTH_FAILED` | 服务器原话 + 用户名 | 禁止自动重试消耗锁定配额 |

- 幂等性：以连接标识为幂等键；同一配置重复建立复用既有连接。
- 超时/重试：用户可见的连接失败只报一次；不自动重试认证失败。
- 禁止行为：禁止把口令写进错误 Body 或日志；禁止在未选库时把连接标成「已就绪」。

### 4.2 连接删除

对应需求：`FR-STD-DB-CONN-001`、`FR-STD-DB-CONN-002`

- 用途：删除连接及其派生数据。调用方：连接管理。实现方：连接管理 + 凭据存取。
- 请求参数：连接标识（标识，必填，必须存在）。
- 成功响应：删除的连接标识 + 连带清理项清单（凭据条目、连接缓存、保活任务）。
- 失败响应：`CONN_NOT_FOUND`（不存在，禁止返回空成功）/ `CRED_PURGE_FAILED`（凭据未能清理，必须明说残留位置）。
- 幂等性：重复删除返回「已不存在」而不是成功。
- 禁止行为：禁止只删列表项而留下凭据；禁止在存在执行中语句时删除连接（必须先取消或明确拒绝）。

### 4.3 语句执行

对应需求：`FR-STD-DB-EXEC-001`、`FR-STD-DB-EXEC-002`

- 用途：对选中或整篇 SQL 执行，逐条上报进度。调用方：查询页签。实现方：执行与事务。
- 请求参数：

| 参数 | 类型 | 必填 | 校验规则 | 说明 |
|---|---|---|---|---|
| 连接标识 | 标识 | 是 | 已连接 | 上下文由选中连接决定 |
| 目标库 | 文本 | 是 | 与上下文栏一致 | 不一致即拒（任务定义同规则） |
| SQL 文本 | 文本 | 是 | 非空；有选区取选区，无选区取整篇 | 范围自动判定 |
| 事务模式 | 枚举 | 是 | 自动提交 / 手工 | 手工模式下语句同事务 |
| 参数值 | 映射 | 否 | 占位符 `:name` 与 `$1` 类型化转义 | 禁止字符串拼接 |
| 最大显示行数 | 整数 | 是 | > 0，默认 200 | 只影响渲染，不改变结果正确性 |

- 成功响应：逐条状态序列（第 N 条正在执行 / 完成 / 失败）+ 每结果集的行列数与耗时 + 影响行数 + 错误原文（若有）。
- 失败响应：

| 场景 | 错误码 | Body | 禁止行为 |
|---|---|---|---|
| SQL 为空 | `EXEC_EMPTY_SQL` | 可读提示 | 禁止静默无动作 |
| 未选连接 | `EXEC_NO_CONNECTION` | 提示先选连接 | 禁止默认连第一个连接 |
| 只读连接遇写语句 | `EXEC_READONLY_DENIED` | 哪条语句 + 只读原因 | 禁止提供「仍然执行」绕过入口 |
| 高危语句未确认 | `EXEC_CONFIRM_REQUIRED` | 待确认语句清单 | 禁止先执行后补确认 |
| 服务端报错 | `EXEC_SERVER_ERROR` | 服务器原文 + 语句序号 | 禁止改写成模糊文案；禁止崩溃 |
| 连接中断 | `EXEC_CONNECTION_LOST` | 断在哪条语句 + 事务是否回滚 | 禁止假装成功；禁止静默重连后重放写语句 |

- 幂等性：查询类天然幂等；写类**不自动重试**，由人决定。
- 超时/重试：执行可被取消；取消后连接仍可用。
- 禁止行为：禁止并发打乱同一批语句顺序；禁止执行中允许关闭页签（§6.4）；禁止把多结果集只留最后一个。

### 4.4 执行取消

对应需求：`FR-STD-DB-EXEC-001`、`FR-STD-DB-EXEC-002`

- 用途：取消当前执行并使服务端语句真被取消。调用方：工具栏停止按钮。实现方：执行与事务 → 驱动。
- 请求参数：执行标识（标识，必填，必须属于当前连接）。
- 成功响应：取消结局（成功取消 / 服务端已结束）+ 耗时。
- 失败响应：`EXEC_CANCEL_ILLEGAL`（执行标识不属于本连接：禁止「尽力取消」）/ `EXEC_CANCEL_FAILED`（服务端拒绝，原话上浮）。
- 幂等性：重复取消返回同一结局。
- 禁止行为：禁止只停界面不停服务端；禁止取消后把连接标成不可用。

### 4.5 元数据列举

对应需求：`FR-STD-DB-META-001`、`FR-STD-DB-META-002`

- 用途：按类型层级取对象树与表结构。调用方：对象树、上下文栏。实现方：驱动与方言。
- 请求参数：连接标识、层级路径（可选，缺省取根）、刷新标志。
- 成功响应：节点列表（名称、种类、是否有子节点）+ 表结构（列名、类型、可空、默认值、注释）+ 取数耗时。
- 失败响应：`META_UNSUPPORTED`（该类型不支持该层级，必须说明层级差异） / `META_FAILED`（原话）。
- 幂等性：读取幂等。
- 禁止行为：禁止把不同数据库类型的层级强行统一；禁止刷新时清空用户已选中节点；禁止在树里伪造「加载中」以外的占位节点。

### 4.6 表数据浏览与行编辑

对应需求：`FR-STD-DB-DATA-001`、`FR-STD-DB-DATA-002`

- 用途：浏览前 N 行、条件过滤、按行改写并写回。调用方：查询页签。实现方：执行与事务。
- 请求参数：连接标识、目标表、行数上限（默认 200）、过滤条件（WHERE / ORDER BY，服务端执行）、待改行集合（主键或唯一标识 + 新值）。
- 成功响应：结果集 + 可编辑判定 + 每行写回结局（成功 / 影响 0 行 / 冲突）。
- 失败响应：`DATA_NO_PK`（无可定位标识时禁止提供行编辑入口）/ `DATA_WRITE_CONFLICT`（行已被他人改动，原话）+ `DATA_WRITE_FAILED`。
- 幂等性：写回以主键为幂等键；影响 0 行必须如实报冲突而非成功。
- 禁止行为：禁止无 WHERE 的整表写回；禁止把「影响 0 行」当成功；禁止在只读连接上开放写回。

### 4.7 结构脚本生成与执行

对应需求：`FR-STD-DB-DDL-001`、`FR-STD-DB-DDL-002`

- 用途：由列定义生成建表/删表/清表脚本并在确认后执行。调用方：对象树菜单、表设计视图。实现方：结构变更 → 执行与事务。
- 请求参数：列定义集合（名称、类型、可空、默认值）、目标表、脚本种类（建 / 删 / 清）。
- 成功响应：脚本文本（供预览）+ 执行结局；删表默认带「存在才删」语义。
- 失败响应：`DDL_PREVIEW_REQUIRED`（未预览即执行：拒绝）/ `DDL_CONFIRM_REQUIRED`（未二次确认）/ `DDL_FAILED`。
- 禁止行为：禁止跳过预览；禁止把 DDL 当普通查询静默执行；禁止生成脚本时写入用户数据或口令。

### 4.8 导入与导出

对应需求：`FR-STD-DB-IO-001`、`FR-STD-DB-IO-002`

- 用途：结果集导出多格式；整表/整库流式导出；文件导入。调用方：结果区、对象树。实现方：导入导出。
- 请求参数：来源（结果集 / 表 / 库）、格式（CSV / JSON / TSV / Markdown / INSERT）、目标路径、编码与换行、导入时目标表与列映射。
- 成功响应：任务进度（已写行数 / 总行数可选）+ 完成结局 + 文件大小。
- 失败响应：`IO_FORMAT_UNSUPPORTED` / `IO_TARGET_EXISTS`（导入目标已存在必须询问而非覆盖）/ `IO_PARTIAL`（部分成功：必须列出成功与失败项）。
- 禁止行为：禁止导出含口令、连接串原文或敏感字面量；禁止导入失败后留下半成品且不告知；禁止把整表读进内存再写文件（流式写）。

### 4.9 服务器会话管理

对应需求：`FR-STD-DB-SESS-001`、`FR-STD-DB-SESS-002`

- 用途：列会话、取消会话内当前语句、终止会话。调用方：会话视图。
- 请求参数：连接标识、会话标识（进程号）、动作（列出 / 取消语句 / 终止）。
- 成功响应：会话列表（进程号、用户、库、客户端地址、状态、等待事件、已运行时长、当前 SQL）；动作结局。
- 失败响应：`SESS_NOT_FOUND` / `SESS_KILL_DENIED`（权限不足：原话）/ `SESS_KILL_REQUIRED_CONFIRM`。
- 禁止行为：禁止无二次确认终止会话；禁止不说明「会掐断连接并回滚未提交事务」就执行终止。

### 4.10 助理上下文传递

对应需求：`FR-STD-WS-AI-001`、`FR-STD-WS-AI-002`

- 用途：把当前连接、库表、选中 SQL 的文本与标识投给对话页签。调用方：工作区。实现方：助理桥。
- 请求参数：连接标识、库表标识、选中 SQL 文本、投递方式（显式确认 / 自动附带）。
- 成功响应：已投递的上下文摘要（便于用户核对）+ 是否含行数据（含则必须已确认并留痕）。
- 失败响应：`BRIDGE_ROW_DATA_REQUIRES_CONFIRM`（含行数据未确认：拒绝）/ `BRIDGE_EMPTY_CONTEXT`。
- 禁止行为：禁止投递结果行数据而不确认；禁止投递凭据或连接串原文；禁止让助理据此直接执行写操作而不经 §4.3 的审批链。

## 6. 状态机与流转规则

### 6.1 连接

对应需求：`FR-STD-DB-CONN-001`、`FR-STD-DB-CONN-002`

允许状态（闭集）：`未连接`、`连接中`、`已连接`、`断开中`、`失败`。

| 当前状态 | 事件/条件 | 目标状态 | 副作用 | 实现位置 |
|---|---|---|---|---|
| 未连接 | 建立请求且校验通过 | 连接中 | 取凭据、不落日志 | 连接管理 |
| 连接中 | 握手成功 | 已连接 | 启动保活（若开启） | 连接管理 |
| 连接中 | 握手/认证失败 | 失败 | 上浮原话，不起重试 | 连接管理 |
| 已连接 | 断开请求 | 断开中 | 取消进行中语句前需确认 | 连接管理 |
| 已连接 | 服务端断开/网络断 | 失败 | 标记事务未知并明说 | 驱动 |
| 断开中 | 资源释放完成 | 未连接 | 清理缓存句柄 | 连接管理 |
| 失败 | 重新建立 | 连接中 | — | 连接管理 |

禁止的流转：禁止 `失败 → 已连接` 跳转（必须先经 `连接中`）；禁止 `已连接` 期间并发建立第二条同配置连接（复用同一条）；禁止新增未列状态。

### 6.2 语句执行

对应需求：`FR-STD-DB-EXEC-001`、`FR-STD-DB-EXEC-002`

允许状态：`待发`、`执行中`、`已完成`、`已取消`、`失败`。

| 当前状态 | 事件/条件 | 目标状态 | 副作用 | 实现位置 |
|---|---|---|---|---|
| 待发 | 开始执行 | 执行中 | 上报「第 N 条」 | 执行与事务 |
| 执行中 | 服务端返回 | 已完成 | 落结果集、写执行记录 | 执行与事务 |
| 执行中 | 取消请求 | 已取消 | 服务端真取消、留痕 | 执行与事务 |
| 执行中 | 服务端报错/断连 | 失败 | 错误原文上浮、标记事务状态 | 执行与事务 |
| 已取消 | — | 终态 | 不可恢复，重跑需人发起 | — |
| 失败 | — | 终态 | 同上 | — |

禁止的流转：禁止 `已完成 → 执行中`（重跑必须是新的一次执行）；禁止 `已取消 → 已完成`；禁止跳状态；禁止在 `执行中` 关闭页签。

### 6.3 审批单

对应需求：`FR-STD-DB-TASK-001`、`FR-STD-DB-TASK-002`

允许状态：`待审`、`已批准`、`已拒绝`、`已过期`。

| 当前状态 | 事件/条件 | 目标状态 | 副作用 | 实现位置 |
|---|---|---|---|---|
| 待审 | 人工确认 | 已批准 | 记录确认人与时刻 | 任务与审批 |
| 待审 | 人工拒绝 | 已拒绝 | 留痕，不发语句 | 任务与审批 |
| 待审 | 会话结束/超时 | 已过期 | 留痕 | 任务与审批 |
| 已批准 | 执行 | （不改审批终态） | 回执另记 | 执行与事务 |

禁止的流转：禁止 `已拒绝 → 已批准`；禁止 `已过期 → 已批准`；过期与撤回的终局口径见 §14.1 第 4 条（未定，遇到即 `BLOCKED`）。

### 6.4 查询页签

对应需求：`FR-STD-WS-UI-001`、`FR-STD-WS-UI-002`

允许状态：`新建`、`干净`、`有未保存改动`、`已保存`、`执行中`、`已关闭（可恢复）`。

| 当前状态 | 事件/条件 | 目标状态 | 副作用 | 实现位置 |
|---|---|---|---|---|
| 新建 | 首次输入 | 有未保存改动 | 脏标记 | 页签与会话 |
| 有未保存改动 | 保存成功 | 已保存 | 写盘、记路径 | 页签与会话 |
| 已保存 | 再次编辑 | 有未保存改动 | 脏标记 | 页签与会话 |
| 干净/已保存 | 关闭 | 已关闭（可恢复） | 进会话快照 | 页签与会话 |
| 有未保存改动 | 关闭 | 需确认 | 确认后进快照 | 页签与会话 |
| 执行中 | 关闭请求 | 拒绝 | 明说「执行中，请先停止」 | 页签与会话 |

禁止的流转：禁止 `执行中 → 已关闭`；禁止关闭时静默丢弃未保存内容；禁止恢复时重放已执行语句。

## 7. 关键流程与调用顺序

### 7.1 查询执行全链

对应需求：`FR-STD-DB-EXEC-001`、`FR-STD-DB-EXEC-002`

允许的调用顺序：

1. 界面 → §4.1 连接建立（复用已连接则跳过握手）。
2. 界面 → 执行前校验：SQL 非空、连接已选、目标库与上下文栏一致。
3. 执行与事务 → 高危判定：只读连接遇写语句直接拒（§4.3）；无 WHERE 的 `UPDATE`/`DELETE`、`DROP`/`TRUNCATE` 走 §4.3 的确认要求。
4. 界面 → 人确认（需要时）→ 执行与事务 → 驱动：按文本顺序逐条执行。
5. 每完成一条：上报状态 → 结果集保留 → 写执行记录（§5.2）→ 审计留痕。
6. 全部结束：汇总行列数与耗时，恢复工具栏空闲态。

禁止的调用顺序：

- 禁止未选连接就默认取第一条连接执行。
- 禁止在 §4.3 校验失败后仍进入执行阶段。
- 禁止把用户取消当成「执行完毕」继续写执行记录的成功分支。
- 禁止绕过执行与事务直接由界面调驱动。

失败处理：

| 失败点 | 必须行为 | 禁止行为 |
|---|---|---|
| 连接不可用 | 停止，明说连接状态与下一步 | 静默重连后重放写语句 |
| 第 N 条失败 | 停止后续语句，上浮服务器原文与序号，标记事务未知/已回滚 | 继续执行剩余语句；改写成模糊文案 |
| 取消 | 服务端真取消，结局如实上报，连接保持可用 | 只停界面 |
| 归档失败 | 如实报「记录未落盘」，业务结果不回滚 | 假装归档成功 |

### 7.2 结构变更与高危写

对应需求：`FR-STD-DB-DDL-001`、`FR-STD-DB-DDL-002`、`FR-STD-DB-TASK-001`、`FR-STD-DB-TASK-002`

允许顺序：

1. 对象树/表设计 → §4.7 生成脚本文本（不执行）。
2. 预览：界面展示完整脚本 + 目标表 + 类型。
3. 二次确认（删除类须手输表名或等价强确认）→ §4.7 执行。
4. 执行结束写执行记录与审计；回执按 §5.4 记读数。

禁止：

- 禁止跳过预览直接执行 DDL。
- 禁止把「预览成功」当「执行成功」。
- 禁止在只读连接或只读任务上执行 DDL。
- 禁止对影响行数超上限的任务继续执行。

### 7.3 文件编辑、保存与外部改动

对应需求：`FR-STD-WS-FS-001`、`FR-STD-WS-FS-002`、`FR-STD-WS-EDIT-001`、`FR-STD-WS-EDIT-002`

允许顺序：

1. 打开或新建 → 识别文件类型 → 编辑器就绪。
2. 编辑：脏标记置位；撤销按 §5 语义合并。
3. 保存：有路径直接写回；无路径进入另存流程（系统保存面板）。
4. 外部改动监听发现磁盘变更 → 提示「磁盘上已变」→ 让用户选择重新载入或保留本地（不得静默覆盖任何一侧）。

禁止：

- 禁止静默覆盖磁盘上被外部改过的内容。
- 禁止把编码/换行猜测结果写死进文件而不告知。
- 禁止在保存失败时清除脏标记。

### 8.3 导航与流转契约

允许的流转：

| 起点 | 触发 | 终点 | 前置条件 | 禁止行为 |
|---|---|---|---|---|
| 活动栏 | 点「数据库」 | 查询页签 | 有可用连接（无连接先给建连引导） | 禁止直接报错 |
| 对象树节点 | 双击表 | 新查询页签（浏览前 N 行） | 连接已就绪 | 禁止在未连接时打开空页签 |
| 查询页签 | 执行成功 | 同页签结果区 | 至少一条语句完成 | 禁止自动跳到别的页签 |
| 会话视图 | 终止会话 | 同视图 | 已二次确认 | 禁止未确认离开 |

禁止的流转：禁止从对话页签直接跳转执行写操作而不经审批；禁止未确认离开导致未保存内容丢失；禁止新增未列出的路由或入口。

### 8.4 界面状态契约

| 状态 | 必须呈现 | 禁止行为 |
|---|---|---|
| 加载中 | 进度或等待指示；关键操作按钮禁用 | 空白无反馈；允许重复提交 |
| 空数据 | 空态文案 + 引导动作（如「新建连接」「打开文件」） | 显示错误；空白页无说明 |
| 错误 | 位置 + 原因 + 重试入口（§9 包装后） | 静默失败；用空数据冒充成功 |
| 权限不足 | 明说缺什么（授权能力位 / 服务器权限）与怎么给 | 先展示操作再报错；把入口做成灰色诱导 |
| 提交中 | 按钮进入进行中态且不可重复点击 | 无反馈；重复发起请求 |
| 部分失败 | 明确列出失败项与成功项 | 整体回滚却不告知；静默忽略失败项 |

### 8.5 交互规则

必须做：

- 表单校验通过前提交按钮保持禁用；请求进行中按钮不可重复点击。
- 不可逆操作（删连接、删表、清表、终止会话、执行高危写）先二次确认，并说明后果。
- 每个异步操作有进行中与结果反馈；执行中页签的关闭入口被拒并给出理由。
- 错误文案来自统一文案表，不即兴撰写。

禁止做：

- 禁止把关键操作藏在二级菜单之外无法发现的位置，或反之只放在二级菜单。
- 禁止用 toast 承载需要用户决策的错误。
- 禁止在前端做仅后端/驱动可信任的权限判断（只读、能力位以能力层判定为准）。
- 禁止静默吞掉接口错误。

### 8.6 表单与校验契约

| 表单/字段 | 前端校验规则 | 后端校验规则 | 错误呈现位置 | 禁止行为 |
|---|---|---|---|---|
| 连接名称 | 非空、同工作区唯一 | 同左 | 字段下方 | 禁止仅前端校验 |
| 主机 | 非空 | 同左 | 字段下方 | 禁止在前端拼连接串 |
| 端口 | 整数 1–65535，先解析再校验 | 同左 | 字段下方 | 越界值静默夹取而不提示 |
| 用户名 | 非空 | 同左 | 字段下方 | 用空口令尝试连接 |
| SQL 文本 | 非空 | 非空 + 目标库一致 | 编辑器下方（错误件）与消息面 | 禁止空执行静默通过 |
| 导出格式 | 取值为支持集合 | 同左 | 字段下方 | 生成不支持格式的空文件 |
| 导入目标 | 目标存在必须询问 | 同左 | 顶部汇总 + 字段 | 静默覆盖既有表 |

前端与后端校验必须一致，后端为最终依据；禁止前端通过即假定后端成功。

### 8.7 界面动作与接口映射

| 界面动作 | 调用接口 | 成功行为 | 失败行为 | 禁止行为 |
|---|---|---|---|---|
| 点执行 | §4.3 | 逐条上报 + 结果区渲染 + 写执行记录 | 错误件 + 保留 SQL | 失败后清空编辑器 |
| 点停止 | §4.4 | 状态改「已取消」+ 连接可用 | 明说服务端拒绝原话 | 只改界面状态 |
| 加载对象树 | §4.5 | 渲染层级 | 错误态 + 重试 | 显示空树冒充无对象 |
| 行写回 | §4.6 | 逐行结局 | 冲突行明示 + 保留输入 | 影响 0 行当成功 |
| 生成脚本 | §4.7 | 展示脚本 + 待确认 | 明说缺什么 | 直接执行 |
| 导出 | §4.8 | 进度 + 完成 | 部分成功列明细 | 失败留半成品不说 |
| 终止会话 | §4.9 | 结局 + 刷新列表 | 权限原话 | 无确认终止 |
| 投递上下文 | §4.10 | 摘要可核对 | 拒绝并说明需确认 | 静默投递行数据 |

### 8.8 错误呈现规则

- 字段级错误呈现在字段附近，禁止只弹全局提示。
- 页面级错误呈现在结果区或页面顶部，必须含原因与重试入口。
- 服务器错误必须保留原文（可复制），并附语句序号与目标库。
- 不可恢复错误（连接彻底不可用、授权失效）必须阻断当前动作并给出下一步，禁止让用户停在状态不一致的界面。
- 文案来自统一文案表与错误码映射（§9）。

### 8.9 可访问性与一致性

- 必须：键盘可达、焦点可见、语义化标签；工具栏每个按钮有 tooltip 与快捷键且只在一处定义。
- 禁止：仅靠颜色传达状态；占用系统级快捷键；同一动作在两处各写一份快捷键表。

## 9. 错误处理与兜底规则

对应需求：`FR-STD-DB-EXEC-001`、`FR-STD-DB-CONN-001`、`FR-STD-DB-SESS-001`

错误分级三级，判据是「界面还能不能继续走」：

| 级别 | 判定 | 界面表现 | 禁止 |
|---|---|---|---|
| 可恢复 | 换输入 / 换连接 / 重试即好 | 就地提示 + 重试入口 | 弹模态打断；丢已输入 |
| 阻断 | 当前动作做不下去，应用还能用 | 明说原因与下一步 | 静默降级；假装成功 |
| 静默 | 只进日志（如缓存清理失败） | 无提示 | 用它掩盖影响结果的问题 |

错误码清单：

| 错误码 | 含义 | 状态 | 触发条件 |
|---|---|---|---|
| `CONN_INVALID_CONFIG` | 连接参数非法 | 400 | 字段校验失败 |
| `CONN_NO_CREDENTIAL` | 凭据缺失或不可解 | 401 | 密钥存储无条目 |
| `CONN_UNREACHABLE` | 主机不可达/超时 | 503 | 网络或端口问题 |
| `CONN_AUTH_FAILED` | 认证失败 | 401 | 服务器拒绝 |
| `CONN_NOT_FOUND` | 连接不存在 | 404 | 删除或引用已删连接 |
| `CRED_PURGE_FAILED` | 凭据未清理 | 500 | 密钥存储写失败 |
| `EXEC_EMPTY_SQL` | SQL 为空 | 400 | 编辑器内容为空 |
| `EXEC_NO_CONNECTION` | 未选连接 | 409 | 无活动连接 |
| `EXEC_READONLY_DENIED` | 只读连接遇写 | 403 | 只读模式 |
| `EXEC_CONFIRM_REQUIRED` | 需高危确认 | 409 | 无 WHERE 写、删表类 |
| `EXEC_SERVER_ERROR` | 服务端报错 | 422 | 语句执行失败 |
| `EXEC_CONNECTION_LOST` | 连接中断 | 503 | 链路断开 |
| `EXEC_CANCEL_ILLEGAL` | 取消请求非法 | 409 | 执行标识不属于本连接 |
| `META_UNSUPPORTED` | 该类型不支持该层级 | 400 | 层级差异 |
| `DATA_NO_PK` | 无可定位标识 | 409 | 行编辑前置条件缺失 |
| `DATA_WRITE_CONFLICT` | 行已被改动 | 409 | 影响 0 行 |
| `DDL_PREVIEW_REQUIRED` | 未预览即执行 | 409 | 跳过预览 |
| `IO_TARGET_EXISTS` | 导入目标已存在 | 409 | 未确认覆盖 |
| `IO_PARTIAL` | 部分成功 | 207 | 部分行/文件失败 |
| `SESS_KILL_DENIED` | 权限不足 | 403 | 服务器拒绝 |
| `LIC_NO_CAPABILITY` | 无对应能力位 | 403 | 授权不足或到期 |

禁止的兜底方式：返回空对象冒充成功；用默认值掩盖缺失数据；捕获异常后不记录、不返回、不处理；把依赖失败静默降级为业务成功。

日志要求：必须记错误码、连接标识、会话/页签标识、调用方、时间；禁止记口令、凭据引用原文、完整连接串、结果行数据。

## 10. 被拒绝的替代方案

| 被拒绝方案 | 拒绝原因 | 对 Agent 的约束 |
|---|---|---|
| 把只读连接当「可强制写」（提供「仍然执行」按钮） | 会让人误以为只是确认，实际绕过安全边界 | 不得提供绕过入口 |
| 用 `EXPLAIN ANALYZE` 估算影响行数 | 会真的执行目标语句（等于未经批准的写） | 只能 `EXPLAIN (FORMAT JSON)`；取不到行数如实写「未接」 |
| 行数预估用表总行数或本地猜测 | 假数会被当成批准依据 | 只认优化器给出的行数 |
| 写语句自动重试 | 等于偷偷多执行一次 | 写不自动重试，由人决定 |
| 界面层缓存数据库服务对象 | 跨页签会出现两条连接与两个事务 | 服务按「连接 + 库」缓存并共享 |
| 把整表读进内存再导出 | 大结果必然爆内存 | 走流式写文件 |
| 多语句并发执行 | 打乱顺序、事务语义崩坏 | 按文本顺序逐条执行 |
| 未授权入口显示成灰色 | 等于诱导点击后报错 | 不出现（不是灰掉） |
| 到期即锁死数据 | 用户数据被许可证绑架 | 到期只降级入口，数据可开可导出 |
| 结果行数据默认投给助理 | 数据外发不可控 | 必须显式确认并留痕 |
| 把实现读数（用例数、真库读数）写进契约 | 每批都变，必然腐烂 | 读数只进台账 |
| 用只读日志面板冒充终端 | 让人以为能交互 | 终端必须是真交互式 shell |

## 11. 非功能设计约束

对应需求：`FR-STD-ALL-BLD-001`、`FR-STD-ALL-BLD-002`、`FR-STD-ALL-IFACE-001`、`FR-STD-ALL-IFACE-002`

- 性能：首屏行批 ≤ 200 ms；大结果按需渲染不冻结界面；查询取消 2 s 内给出结局（成功取消或失败原因）；对象树刷新不阻塞编辑。
- 安全：口令只经密钥存储取用、只在内存中存在；用户数据不出本机（模型调用与既授权同步除外）；外部工具输出一律不可信；结果行数据投递需确认。
- 并发：同一连接上的语句串行；服务按「连接 + 库」唯一；同一连接并发请求复用同一物理连接；配置写入原子。
- 可观测：每个动作写审计（追加式）；慢查询记耗时与语句摘要；错误日志带错误码与关键标识。
- 依赖清单：
  - 允许：平台既有工具链与系统框架；每类已接入数据库各一支驱动；本机库（vendored）；测试框架；构建与门禁脚本。
  - 禁止：消息队列、独立后端服务、云数据库代理、多租户框架、第二套令牌/文案真源、可卸载插件容器（插件为同进程模块）。
- 部署/运行约束：单机运行、离线可用（模型调用与既授权同步除外）；配置只读自三处真源（主题令牌 / 文案表 / 密钥存储）；不引入常驻后台服务。
