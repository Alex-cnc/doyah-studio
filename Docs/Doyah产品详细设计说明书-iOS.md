### 0.2 与 Android 基准的差异登记（逐节表态）

> 每一行 = 安卓详设 §3 的一节 → 本端处置。`沿用` = 语义照搬；`差异` = 业务语义同、平台手段不同；`不适用` = 本端没有这个面。

| 安卓节 | 处置 | 依据 / 本端落点 |
|---|---|---|
| `§3.1` | 沿用 | 捕获路径语义照搬（触发即输入、无选择步骤、保存即本机可读、联网前是「待同步」） |
| `§3.2` | 差异 | 附件选择端上不同：安卓走 SAF / 系统选择器，iOS 走 `UIDocumentPicker` 与相册；库内只存引用、相同内容只存一份这条不变 |
| `§3.3` | 沿用 | 检索按 `Character` 偏移切分、命中不重叠、返回总数与首命中 —— 与基准端同口径 |
| `§3.4` | 差异 | 私密解锁手段不同：安卓用系统生物识别；iOS 用 `LocalAuthentication`（Face ID / Touch ID）并在失败时回退设备口令；**出口一律排除**这条不变 |
| `§3.5` | 沿用 | 完成 / 重开 / 改期只走既有写入口；日期算术只在 `core` |
| `§3.6` | 沿用 | 一条笔记唯一归属一个笔记本、未指定落默认收件箱、移动只改归属一列（§3.6 已按基准端补齐） |
| `§3.7` | 差异 | 连续翻页的承载不同：安卓是三页并排 + `Animatable` 位移；iOS 用横向分页容器（`UICollectionView`）承载三页，位移 `UIView.animate`，阈值 = 页宽 × 0.22 且不小于 44 pt（iOS 最小触控尺寸），同样**不叠透明度动画** |
| `§3.8` | 差异 | 关于页版式同为四行 + 功能清单，但版本号读 `CFBundleShortVersionString` / `CFBundleVersion`（安卓读 `BuildConfig.VERSION_NAME`） |
| `§3.9` | 差异 | 默认首页设置键仍为 `notes.home`（`todo` / `notes`），落点换成 `UserDefaults`；缺键与非法值一律按 `todo`，只影响冷启动 |

## 1. 基线与禁止项

| 项 | 取值 | 说明 |
|---|---|---|
| 语言 | Swift（SwiftPM + Xcode 工程） | 与 `tools/logic-check/path-ownership.json` 的 `ios` 树口径一致 |
| 最低版本 | 开工时按基准端能力确定并写进本节 | 定下后改需批准 |
| 存储 | 本机 SQLite（数据家在应用沙箱） | 库表取概设 §5 / §15 |
| 网络 | 仅已授权同步出口 | 私密与行数据永不出端 |
| 归属 | `[独占:ios]`（本格由 iOS 组员维护） | 跨端条款不在此改 |

禁止项：禁止在本目录另写数据/错误码契约；禁止为空目录建占位工程「装样子」；禁止跨格修改 Android / 鸿蒙实现。

## 2. 分层（按基准端结构对齐）

| 层 | 职责 | 与基准端对应 |
|---|---|---|
| 共享能力层 | 捕获、存储、检索、待办、私密规则 | 对应 Android `core/commonMain`，逻辑口径逐条对拍 |
| 界面层 | 列表 / 正文 / 待办 / 搜索 | 对应 Android `app`，行为按概设 §8 |
| 平台接入 | 文件访问、通知、快捷键 | iOS 专有 |

调用：界面 → 能力 → 本机存储；**禁止**能力层依赖界面。

## 3. 关键契约（与基准端同口径）

### 3.1 捕获

- 后置：触发即输入，无选择步骤；保存即本机可读；无网状态为「待同步」
- 禁止：必填归属/模板；空标题阻断保存（缺省取正文首行，空则「无标题」）
- 测试：`T-3.1-01`

### 3.2 附件

- 后置：库内只存引用；相同内容一份；显示操作不改原字节
- 禁止：字节入库；引用缺失画空框
- 测试：`T-3.2-01`

### 3.3 检索

- 后置：按字符偏移切分（中文不错位）；命中不重叠；返回总数与首命中
- 测试：`T-3.3-01`

### 3.4 私密

- 后置：私密条目端内可用，出口（导出/分享/日志/同步）一律排除
- 测试：`T-3.4-01`

### 3.5 待办

- 后置：完成/改期只走既有写入口；日期算术集中一处，界面不自算
- 测试：`T-4.3-01`

## 4. 数据与状态

- 库表与事务边界取概设 §5 / §15；正文权威源 = span 树，视图为投影。
- 自动保存守卫（许可 / 有内容 / 有改动）；`pending` 期间再编辑不丢键。
- 删除分级：回收站 → 彻底清除二次确认。

## 5. 界面

| 视图 | 必须呈现 | 禁止 |
|---|---|---|
| 笔记列表 | 分区、条数、私密标记 | 同步令牌 |
| 正文编辑 | 保存态、附件引用 | 空框 |
| 待办 / 日历 | 完成、改期、档位 | 界面自算日期 |
| 搜索 | 命中高亮、总数 | 联网结果 |

六态齐（加载/空/错误/权限不足/提交中/部分失败）。

## 6. 错误

| 类别 | 呈现 | 禁止 |
|---|---|---|
| 沙箱不可写 | 明确原因 + 重试 | 静默丢内容 |
| 附件缺失 | 原名与原位置 | 空框 |
| 同步失败 | 「待同步」 | 报成保存失败 |

## 7. 非功能

- 离线可用：无网无账号全功能可用。
- 性能：千条级列表滚动不掉帧；详情打开 < 300 ms。
- 权限：仅申请必需权限；拒绝后降级但可读。
