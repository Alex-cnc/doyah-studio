## 约定（三仓通用）

- **文件命名**：`NNNN-短标题.md`（四位序号，递增；**不复用、不重编号**，作废就标 `已作废`）
- **状态字段（必须有，取值固定）**：`草案` / `待采纳` / `已采纳` / `驳回` / `已作废`
- **必填字段**：提出方（`macos 侧（大河马）` / `windows 侧（小河马）` / `需求提出者`）、日期、
  影响面（契约节号 / 平台实现节号 / 目录）、提案正文、**采纳后回填关联提交 SHA**
- **落笔权**：契约层由 **macOS 侧（大河马）** 执行；平台实现层由**该平台侧**执行
- **痕迹**：改契约层的提交信息写 `contract-change：理由（proposal NNNN）`
- **模板**：`_TEMPLATE.md`
