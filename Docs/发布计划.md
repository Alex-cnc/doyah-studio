## 1. 口径（三条不变量）

1. **自用版**：交付物 = 能装能跑的本机 `.app`（首次打开右键「打开」）；不签名、不公证、不分发。
2. **版本 = 收敛工具**（用户原话：「我只是想用版本把功能规划起来，现在感觉有点乱，无穷无尽」）⇒ 核心是 **§3 版本地图**：**每条未完成项都必须指派到一个版本格（含「不做」格）**，不许留在「待办池」里；**新需求入队必须同时给出「进哪个版本」**。
3. **达标判据 ≠ 清单清零**：① 该版声明的**使用场景闭环**（§4）；② 机械门禁全绿（`verify-all.sh` 18 项）；③ 自用版加一条 —— **连续用一周无阻塞性缺陷**。

## 4. Alpha 1 的「完整功能」怎么算（场景 + 逐条，而不是条数感觉）

**四个自用场景**（都是你真实用法）：

1. **日常查数**：连库 → 对象树找表 → 写 SQL → 跑 → 看结果 → 复制 / 导出
2. **改东西**：改数据（带事务）、改表结构（改列 / 变更集）、导入 CSV / Excel
3. **在终端里干活**：下方面板终端跑 `dsh-tui` 之类（例如写公众号）
4. **换外观**：「外观」里**一键切主题**（豆芽绿 / 玫瑰金 / 科技蓝三选一，深浅两态都过门槛）

判定：① 四场景都顺；② 数据库域 + 工作区域 🟡 **逐条落定**（能机器验的补证据；不能的进「Alpha 1 不含」清单）；③ `verify-all.sh` 18 项绿；④ `.app` 实测可装可跑。

## 5. 版本冻结规则

1. **冻结**：各交付日当天 00:00 起 —— 只接受**致命缺陷**修复（崩溃 / 数据损坏 / 起不来），其余进下一版。
2. **解冻**：需需求提出者一句话；本侧不得自行解冻（循环协议红线 14 引用本条）。
3. **交付齐套**：每版齐 **tag + 发布说明 + 「本版不含」清单 + 机械判据**。
4. **Alpha 1 特殊**：09-30 是硬日（十一前），无机动日 —— 若非致命问题一律记入国庆修复队列，不挡交付。

## 7. 风险与缓冲

1. **Alpha 1 窗口只有 ~1 天**（09-29 晚～09-30 晚）：靠「机器可验的先推全绿 + 外部实例项显式划出」保住交付；点验类不阻塞交付（国庆期间你顺手测）。
2. **瓶颈仍是点验与环境实例**，不是开发量：循环 ~15~20 分钟/轮、每轮稳定收一条。
3. **双写撞号**：本侧循环与 Windows 侧同仓并行，按既有「取并集 + 本侧版本号顺延」规则解。
4. **iOS 装机现实约束**：免费 Apple ID 证书 7 天有效期，到期连一次 Mac 重签（自用可接受）。
5. **Retro（Alpha 3）是三条线里最冷的一条**：本侧只做 macOS 首版，范围收在「导入 → 复盘 → 标注」主链，不做花活。
