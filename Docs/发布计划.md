## 2. 各版本功能点与出口判据

**内测期（09-29～09-30）**
- 需求提出者：按《待人工验收清单》点验（46 条，附步骤与预期，每条 30 秒~2 分钟）
- 本侧：修内测报回缺陷 + 收队列尾巴（L-74 非文本类型渲染 / L-68 契约对账 / L-75 Xcode 工程口径 / L-72 数字唯一来源）
- 出口：内测 P0 清零；点验第 1 批（界面交互类）通过

**beta.1（10-01）· 工作区 + 笔记补完**
- 编辑器：空态按钮口径 / 折叠态持久 / 合成数据空态 / 面板根 frame 纪律 / 行号列
- 结果集：非文本类型逐型渲染（`inet` `cidr` `macaddr` `interval` `money` 数组 `bit` 范围）
- 笔记：界面检索改走库、本地库与装配收口
- **配色方案 D 已挂起**（需求提出者 2026-09-29：不急）—— 外观框架已成（令牌名 / 对比度门槛 / 样张机制 / 跨平台映射四项齐备），后续新增方案只是「加一组值 + 一节文档」，不阻塞任何版本
- 出口：三模块主链脚本全绿 + `verify-all.sh` 18 项 + 内测 P0 清零 + 双端样张对照

**beta.2（10-03）· 数据库域 🟡 收口 + 智能体域**
- 智能体域 8 条（对话式诊断 / 维护任务编排 / 合成数据 / specs 版本化重跑 / 安全护栏 / MCP 双向 / 技能候选）
- 导入导出 5 条（xlsx / CSV / 整库 / `.et` 口径）+ 会话与服务器管理 3 条
- 出口：FR ✅ 比例冲 85%+；**无新增 ⬜**；未达成项逐条转 `[release 不含]` 或下一版

**beta.3（10-05）· Windows 线合并 + 双端一致**
- Windows Studio（Tauri 2 + Vue 3）首个可跑安装包（MSI/NSIS）+ 结果网格 40 万行压力量化结论
- Windows Retro 骨架重定向（`.sln`/`.NET` → Rust/Tauri）+ 首个可跑壳；Notes Windows 同栈可跑
- **主题（配色方案）三选一落地**：豆芽绿 / 玫瑰金 / 科技蓝（对齐公司 Linux 版已有能力）—— macOS「外观」面板主题下拉 + Windows 同名下拉 + 生成器每主题变量块；判据 = 两端候选同名同值、每主题 × 深浅两态过门槛
- 科技蓝令牌的 Windows 侧同名变量导出 + 双端截图对照
- 出口：Windows 侧闸门 14 项全绿 + 双端同屏对照图

**beta.4 / RC（10-06）· 发布硬化**
- macOS 分发决策收口（沙箱 vs 非沙箱 —— 决定 SSH 隧道 / 终端 `^C` 作业控制 / 备份恢复）+ 签名 + 公证 + DMG

## 3. 版本冻结规则

1. **冻结**：发布日当天 00:00 起进入冻结 —— 只接受**致命缺陷**修复（崩溃 / 数据损坏 / 安全 / 起不来）；其余一律进下一版。
2. **解冻**：需需求提出者一句话；本侧不得自行解冻（循环协议红线引用本条）。
3. **发布齐套**：每个版本必须齐 **tag + 发布说明 + `[release 不含]` 清单 + 机械判据**（本侧 `verify-all.sh` 18 项 / Windows 侧闸门 14 项）。
4. **顺延**：某版出现致命缺陷 → 顺延一天，从 RC 窗口扣（缓冲 = 10-07 白天机动日）。

## 5. 风险与缓冲

1. **真正的瓶颈是点验带宽**，不是开发量：46 条 × ≈1 分钟；假期每天 30 分钟即可跟上。不点验 → release 会带较长 `[release 不含]` 清单（诚实标注，不算失败）。
2. **单循环节奏**：约 15~20 分钟/轮、每轮收一条；beta 期须保持「每轮必绿 + 每 2 天冻结一次」。
3. **双写撞号**：本侧循环与 Windows 侧同仓并行，按既有「取并集 + 本侧版本号顺延」规则解。
4. **环境项**：AI 域 / 导入导出部分条目依赖外部实例与端点，缺则显式划出范围。
5. **缓冲日**：10-07 白天不动，除非 RC 出事。
