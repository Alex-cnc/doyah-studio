## 1. 基线与禁止项

| 项 | 取值 | 说明 |
|---|---|---|
| 语言 | ArkTS（Stage 模型） | `entry/src/main/ets/**`；Ability 在 `entryability/EntryAbility.ets` |
| 构建 | hvigor（`hvigor/` + `build-profile.json5`） | DevEco Studio 工程 |
| 工程声明 | `AppScope/app.json5` 一类 + `module.json5` | 包名与能力声明 |
| 代码规范 | `code-linter.json5` | 提交前必跑 |
| 依赖 | `oh-package.json5` | 新增依赖需批准 |

禁止项：禁止侧载网络能力用于同步之外的用途；禁止在鸿蒙侧复制一份 Android 实现逻辑（必须复用契约与算法口径）；禁止把私密条目写进日志。

## 2. 分层

| 层 | 目录 | 职责 |
|---|---|---|
| 页面/Vue 对应层（ArkUI） | `ets/components/**`、`ets/pages/**` | 列表、正文、灵感卡、详情；只渲染与手势 |
| 逻辑层 | `ets/common/**`、`ets/utils/**` | 编辑历史（`EditHistory.ets`）、日期、文本、错误文案 |
| Ability/系统接入 | `ets/entryability/**` | 生命周期、窗口、文件访问 |
| 资源 | `resources/**`、`AppScope/resources/**` | 文案（含 `en_US`）与图标 |

调用：组件 → 逻辑层 → 存储/系统能力；**禁止**组件直写存储。

## 3. 关键契约

### 3.1 捕获

- 后置：从灵感卡进入即光标可输入，无选择步骤；保存后立即可读；无网时状态为「待同步」而非失败
- 禁止：捕获路径出现必填归属/模板；空标题阻断保存（缺省取正文首行，空则「无标题」）
- 测试：`T-3.1-01`

### 3.2 附件与富文本

- 后置：库内只存引用；显示操作不改原字节；富文本由 `RichTextViewer.ets` 渲染，只读语义
- 禁止：字节入库；引用缺失画空框
- 测试：`T-3.2-01`

### 3.3 文本与检索

- 后置：文本切分按字符（中文不错位），口径与 Android 基准端逐字一致
- 禁止：按字节偏移；各端各自发明切分口径
- 测试：`T-3.3-01`

### 3.4 编辑历史

- 后置：`EditHistory.ets` 管撤销/重做；一段连续输入合并为一次撤销
- 禁止：逐字符撤销；跨文档共享历史栈
- 测试：`T-3.4-01`

### 3.5 待办与日期

- 后置：日期算术集中在 `DateUtils.ets`；完成/改期只走既有写入口
- 禁止：组件内自行计算日期；与基准端口径不一致
- 测试：`T-4.3-01`

## 4. 数据与状态

- 存储：本机库（数据家在应用沙箱），库表与事务边界取概设 §5 / §15；鸿蒙侧**不另写契约**。
- 正文权威源 = span 树；视图是投影。
- 自动保存：守卫（许可 / 有内容 / 有改动）；`pending` 再编辑不丢键。
- 删除分级：条目进回收站；彻底清除二次确认。

## 5. 界面

| 视图 | 必须呈现 | 禁止 |
|---|---|---|
| 灵感卡列表 | 摘要、时间、私密标记 | 同步令牌 |
| 灵感详情 | 正文、保存态、附件引用 | 空框 |
| 待办 / 日历 | 完成、改期、档位 | 组件自算日期 |
| 搜索 | 命中高亮、总数 | 联网结果 |

六态齐；错误文案取 `ErrorText.ets`，禁止即兴撰写。

## 6. 错误

| 类别 | 呈现 | 禁止 |
|---|---|---|
| 库/沙箱不可写 | 明确原因 + 重试 | 静默丢内容 |
| 附件缺失 | 原名与原位置 | 空框 |
| 同步失败 | 「待同步」 | 报成保存失败 |

## 7. 非功能

- 离线可用：无网无账号全功能可用。
- 性能：千条级列表滚动不掉帧；详情打开 < 300 ms。
- 权限：仅申请必需能力；拒绝后功能降级但可读。
