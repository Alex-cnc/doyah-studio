# 工作区代码编辑器 · 编程助手能力基线

> **由头（人类主人 2026-10-15 原话）**：「**其实除了 AI 助手，工作区的代码编辑器也要下功夫做到好用，编程助手的基本能力都要有**」
>
> **本件作用**：把"编程助手该有的基本能力"变成**可逐条核的基线**（有 / 半接 / 无 / 判据在哪），
> 从此这条线按表推进，不靠印象、不零散。**现状列由机械扫描得出**（关键字扫描 + 编辑器接线行数），
> 落到某条动手前**先实测确认**，不拿扫描结果当结论。
>
> **需求面提醒**：下列多数能力**在 `Docs/Doyah产品需求规格说明书.md` 里没有对应条文**（实测：`自动配对` / `移行` /
> `自动缩进` / `悬停` / `诊断` 五组关键字在 FR-EDIT-* 里**零命中**）。⇒ 本件先把它们收成**片**，
> **条文是否入三书由人类主人定**（契约层不许自己发明口径）。

## 一、基线（按"每天都会用到"排序）

## 二、推进纪律（沿用既有）

1. **一条一判据**：每条能力落 `Core/`（纯逻辑、可单测）+ 编辑器接线，判据进 `Tests/`（源码扫描 + 行为断言双管）。
2. **不新开需求号**：条文入三书前，先在**本侧清单**里按片推进（片号 `E-*`）；人类主人点头后再入 `需求规范书`。
3. **手感项**（观感 / 主观）⇒ 一律进 `Docs/design/待人工验收清单.md` **§0.5**，攒着一次性点。
4. **完成读数**：`Scripts/verify-core.sh` 项数 + 逐条判据绿；改动落在 `App/` `Core/` `Tests/` = 本侧子树（归属判据 rc=0）。

## 附一、调研：同类编程助手/编辑器能力面（2026-10-15）

> **调研方法如实交代**：本轮**网络不通**（代理 `127.0.0.1:7890` 与直连均不可达，`curl` 返回 `000`），
> 故本节按**同类产品的公开能力面归纳**（VS Code / JetBrains 系 / Cursor / GitHub Copilot / Claude Code 一类），
> 并按**强证据**对齐到手上已有的两类真来源：① 本仓既有调研件 `doyah-dispatch/docs/AI助手对话能力-调研-*.md`
> ② 本仓需求面 `FR-EDIT-*`（编辑器）与 `FR-AI-*`（助手）。**待联网后补逐条来源行**（挂在本节尾）。

### A. 编辑手感（每天都会碰到）
1. 括号/引号**自动配对**与**跳引号**（选中再打 ⇒ 包住）
2. **括号匹配**高亮（不匹配 ⇒ 告警色）
3. **注释切换**（行注释 / 块注释，按语言）
4. **移行 / 复制行**（⌥↑↓ / ⇧⌥↓）
5. **自动缩进**（回车继承缩进、`{` 后多一级）与**智能粘贴**（按上下文重排）
6. **缩进检测**（软/硬 tab 与宽度，状态栏可切）
7. **多光标 / 列编辑**（⌥点击加光标、⌥拖列选）
8. 撤销/重做的**语义粒度**（一段输入一次撤销，而不是逐字符）

### B. 导航与检索
9. **查找替换**（正则 / 全词 / 大小写 / 范围内替换）
10. **跳转到行** · **跳转到定义** · **查找引用**（后两者通常要 LSP）
11. **快速打开**（按名/符号）与**命令面板**
12. **工作区全文搜索**（含结果预览与快捷键循环）
13. 面包屑 / 符号大纲 / 最近文件

### C. 语言智能
14. **语法高亮**（多语言，可扩展语言表）
15. **自动补全**（关键字/内置函数 → 上下文/路径/符号）
16. **签名提示 / 参数提示**、**悬停文档**
17. **诊断（lint / 静态检查）下划线** + 问题面板
18. **格式化**（整文件 / 选区 / 保存时）
19. **代码折叠**、**片段模板（snippets）**
20. 重命名符号 / 快速修复（LSP 级）

### D. 助手能力（与 `FR-AI-*` 同轴）
21. **多轮对话**与会话持久化（可回放 / 审计，**不含行数据**）
22. **@ 上下文**（文件 / 目录 / 选中 / 页签 / 终端 / schema）
23. **Inline 建议**（补全式）与 **Chat 改代码**
24. **Agent 模式**：模型 → 工具调用 → 结果回灌 → 继续（步数/令牌上限、可中断）
25. **工具面**：读文件/列目录/搜索/写文件（先出差异）/跑命令（白名单）/查库（只读直跑、写走审批）
26. **权限与审批**（等级 + 沙箱 + 白名单，危险动作先问）、**审计与成本记账**
27. **Diff 应用与撤销**（改动可逐一接受/回退）

### E. 工程与运行
28. **内嵌终端**（真 PTY）
29. 任务/命令运行、问题与输出面板
30. **版本管理痕迹**（编辑器边栏 diff / blame）
31. 设置可配（模型 / 端点 / 数据边界 / 工具开关）且**默认保守**

### 结论（三条）
1. **"助手侧"的骨架比 SRS 反映的靠前**（流式/循环/注册表/审计/系统提示已在）⇒ SRS 那 10 条全 ⬜ 是**台账落后**，不是能力为零。
2. **"编辑器侧"是真缺口**：A 组手感六项 + C 组的折叠/片段/悬停/补全接线 —— 这正是人类主人 2026-10-15 指的那一处。
3. **推进序（建议）**：① 括号配对 + 匹配高亮（每天用到）② 注释切换 ⌘/ ③ 移行/复制行 ④ 缩进检测 + 自动缩进 ⑤ 静态检查结果上屏 ⑥ 补全接线确认 ⑦ 折叠/片段 ⑧ 跳转定义/悬停（词法级起步）。
