# Linux 端界面设计参考（v1.0.0 · 2026-11-05）

> **这份文件给谁看**：做 Linux 端（Tauri 2 + WebKitGTK + Vue）界面的人。它不重复设计系统的定义，只回答一件事：
> **照 macOS 的画法，在 Linux 上具体该怎么落**。数值一律取自 `Core/DesignTokens.swift` 与 `Docs/design/terminal-palette.json`，
> 与 macOS 端同源；差异只出现在「平台手段」这一层（字体回退、窗口装饰、快捷键、文件对话框、缩放）。
>
> **为什么需要它**：公司 Linux 端此前没有设计参考，各自照默认控件拼，结果是「能跑但难看」——
> 间距不成体系、字体回退到 DejaVu、深色模式只改了背景、图标尺寸不齐、没有焦点环。第 §9 节把这类成因逐条列出。
>
> 可视化样张：`Docs/design/refs/linux-window-mock.html`（三栏主窗格，深色，按本文数值画的）。

---

## 1. 视觉基准：三件套

| 件 | 出处 | 怎么用 |
|---|---|---|
| 令牌（间距 / 圆角 / 高度 / 分栏） | `Core/DesignTokens.swift`（`Spacing` / `Radius` / `Height` / `Layout`） | 只准用这四组里的值，不许出现裸数字 |
| 调色板（浅 / 深各一套） | `Docs/design/terminal-palette.json`（深海·夜 / 深海·昼） | 界面底色与语义色都从这里取，不许临时调色 |
| 版式样张 | `Docs/design/样张-已实现-浅色-工作区.png`、`样张-令牌-深色.png` | 摆位与层级照它，不重新设计信息架构 |

**令牌取值（唯一的合法数值集）**

| 组 | 值 |
|---|---|
| 间距 | 2 / 4 / 8 / 12 / 16 / 24 / 32 |
| 圆角 | 1 / 4 / 6 / 8 / 10 |
| 高度 | 列表行 20 · 通用行 26 · 控件 26 · 页签 30 · 工具栏 44 · 状态栏 24 |
| 分栏 | 活动栏 46（图标 20）· 侧栏 248（最大 420）· 分隔条 1 |

> 裸数字一律判红（与 macOS 同一条判据）。间距不落在上表 = 排版立刻「松垮」，这是 Linux 端最常见的第一眼问题。

## 2. 窗口与布局

- **最小窗口 1120 × 720**；低于此值不许把三栏硬塞进去，改为折叠侧栏（折叠阈值 1176）。
- 三栏结构（自左向右）：活动栏 46 → 侧栏 248（可拖到 420）→ 主区（编辑 / 网格 / 终端）→ 可选右栏（详情 320）。
- 主区顶部工具栏 44、底部状态栏 24，二者**贯穿整窗**，不随分栏滚动。
- 分隔条宽 1 px，命中区 ≥ 6 px（鼠标不好抓是 Linux 端常被吐槽的点）。
- 窗口标题栏用系统装饰（不做自绘标题栏）：Linux 桌面环境差异太大，自绘会在 KDE / GNOME / i3 上各坏一次。

## 3. 字体与字号（Linux 端差异最大的一节）

| 用途 | 首选 | 回退链 | 字号 / 行高 |
|---|---|---|---|
| 界面文字 | `Inter` | `Noto Sans` → `Source Sans 3` → `Noto Sans CJK SC` → `sans-serif` | 12 / 18 |
| 中文 | `Noto Sans CJK SC` | `Source Han Sans SC` → `WenQuanYi Micro Hei` | 同上 |
| 等宽（代码 / 终端 / 数据网格） | `JetBrains Mono` | `Noto Sans Mono` → `DejaVu Sans Mono` → `monospace` | 12 / 20 |
| 标题 | 同界面文字，600 权重 | — | 14 / 20 |

- **必须显式写 `font-family` 回退链**：Linux 上不写就会落到 DejaVu Sans / 文泉驿，同一份界面在中英文之间字形跳变最刺眼。
- 等宽字体**要有中文字形回退**（`Noto Sans Mono CJK SC`），否则终端里中文变成方框。
- DPI：125% / 150% 缩放时按 `devicePixelRatio` 取整到 1 px；图标用 SVG 或 2x 位图，不许放大 100% 位图。
- 字重只用 400 / 600 两档；不要用 300（WebKitGTK 上细字发虚）。

## 4. 颜色与主题

| 角色 | 深海·夜（深色） | 深海·昼（浅色） |
|---|---|---|
| 窗口底 | `#14171E` | `#FBFBFD` |
| 正文 | `#D6DBE4` | `#23252C` |
| 次文 / 说明 | `#9AA3B2` | `#5C6270` |
| 分隔线 | `#2B303C` | `#E2E5EC` |
| 选中行 | `#24304A` | `#D8E3FF` |
| 强调（可点） | `#6E8BFF` | `#2F55D4` |
| 成功 / 警告 / 危险 | `#5FC98C` / `#E3BF63` / `#F0716F` | `#146B47` / `#7E5500` / `#B23327` |

- 主题跟随系统：读 `prefers-color-scheme`，用户手选优先；**深浅两套必须同时可用**（只做深色 = 半成品，这是 Linux 端第二个常见问题）。
- 对比度门槛：正文 ≥ 4.5:1，大字与图标 ≥ 3:1；焦点环 ≥ 3:1。
- 语义色**只表达状态**（成功/警告/危险/进行中），不做装饰配色。

## 5. 控件规范

| 控件 | 规格 | 禁止 |
|---|---|---|
| 主按钮 | 高 26 · 圆角 6 · 强调色描边或填充 | 一个面板里出现两个主按钮 |
| 次要按钮 | 高 26 · 圆角 6 · 1 px 边框 | 用「灰色不可点」冒充次要按钮 |
| 图标按钮 | 24 × 24 命中区，图标 16 | 同动作换图标；给图标按钮配三行说明 |
| 表单行 | 行高 26 · 标签左对齐 · 校验信息在控件下方 12 | 校验信息用弹窗 |
| 数据网格 | 行 20 · 表头 26 · 等宽字体 · 斑马纹不要 | 横向滚动条压住最后一行 |
| 页签 | 高 30 · 选中项下划线 2 px | 页签宽度随标题跳动 |
| 浮层 | 圆角 8 · 阴影 0 8 24 rgba(0,0,0,.35) | 浮层盖住触发它的按钮 |
| 菜单 | 行 24 · 快捷键右对齐 | 菜单里放说明长句 |
| 滚动条 | 宽 10 · 滑块圆角 5 · 悬停变亮 | 隐藏滚动条（Linux 用户靠它判断内容长度） |
| 焦点环 | 2 px 强调色 + 1 px 外扩 | 去掉 outline（键盘用户在 Linux 上占比高） |

## 6. 六态（每态要一眼能分辨）

| 态 | 呈现 | 禁止 |
|---|---|---|
| 空 | 一句说明 + 一个动作（如「新建连接」） | 空白页；用插图占满屏 |
| 载入 | 骨架屏或逐段出现，超过 400 ms 才显示 | 假进度条；转圈超过 10 s 无文案 |
| 失败 | 机器码对应的人话 + 可重试按钮 + 详情折叠 | 只显示「出错了」；把服务端原文直接抛给用户 |
| 只读 | 控件禁用 + 一句原因（如「只读连接」） | 禁用但不说为什么 |
| 越权 | 入口**不出现**（不是灰掉） | 灰掉并提示「升级可用」 |
| 满态 | 虚拟滚动，滚动条可见 | 一次渲染上万行把窗口卡死 |

## 7. 桌面集成

- **文件对话框走 GTK**（Tauri dialog 插件），不自绘；最近目录要记住。
- 快捷键用 `Ctrl` 系（`Ctrl+S` / `Ctrl+Shift+P` / `Ctrl+K`），**不用 ⌘**；菜单里显示 `Ctrl+…`。
- 通知走 `libnotify`/D-Bus；无通知服务时降级为窗口内提示，不静默丢。
- 托盘项：图标 + 「显示主窗口 / 退出」两项；无托盘环境不阻塞启动。
- 拖放：文件拖进窗口 = 打开（不是导入），目录拖进来 = 切换工作区；拖拽要有落点高亮。

## 8. 与 macOS 的差异对照

| 面 | macOS | Linux |
|---|---|---|
| 快捷键 | ⌘ | Ctrl |
| 窗口装饰 | 自绘（红绿灯） | 系统装饰 |
| 字体 | SF Pro / SF Mono | Inter / JetBrains Mono + Noto CJK 回退 |
| 文件对话框 | NSOpenPanel | GTK FileChooser |
| 通知 | UNUserNotificationCenter | D-Bus / libnotify |
| 滚动条 | 自动隐藏 | 常显（宽 10） |
| 缩放 | 2x Retina | 100 / 125 / 150%，按 DPR 取整 |

除上表之外，**版式、间距、颜色、控件、六态一律照 macOS**；不要另发明一套。

## 9. 「差劲效果」的常见成因（逐条对照自查）

1. 用了默认 GTK/Qt 控件外观，和自绘面板混在一起 —— 圆角、边框、字体三处不一致。
2. 没写字体回退链，中文落到文泉驿、英文落到 DejaVu，同一行字重都不一样。
3. 间距随手写 `margin: 10px`，不落在令牌集上，整屏看着「松」。
4. 只做深色，浅色模式一开就白底黑字刺眼。
5. 图标位图放大到 2x 发虚；同一动作在不同面板用了不同图标。
6. 没有焦点环 —— 键盘用户完全不知道焦点在哪。
7. 滚动条被隐藏，长列表看不出还有内容。
8. 分隔条只有 1 px 命中区，鼠标抓不住。
9. 表格行高 24 以上、单元格没有等宽字体，数字列不齐。
10. 状态栏被内容挤掉 / 跟随滚动 —— 用户看不到连接状态。
11. 空心状态直接空白，用户以为没加载出来。
12. 越权功能灰掉并提示升级 —— 变成广告位。
13. 快捷键写成 ⌘，Linux 上按不出来。
14. 自绘标题栏，在 KDE 上盖住系统按钮。
15. 125% 缩放下 1 px 边框消失或变 2 px。

## 10. 验收清单（15 条，可点验）

| # | 判据 | 怎么看 |
|---|---|---|
| 1 | 窗口 1120×720 下三栏不重叠、状态栏可见 | 拖到最小尺寸 |
| 2 | 全部间距落在令牌集 | 随机抽 5 处量 |
| 3 | 中英文混排无字形跳变 | 标题写中英混排看 |
| 4 | 等宽字体在网格与终端一致 | 对比两处数字 |
| 5 | 深浅两套都可读，对比度达标 | 切换系统主题 |
| 6 | 焦点环在全部可聚焦控件上可见 | 只用键盘 Tab 走一圈 |
| 7 | 分隔条可拖动且命中区够 | 试着抓 1 px 线 |
| 8 | 滚动条常显且宽度一致 | 长列表 |
| 9 | 六态各有一个真实样例 | 断网 / 只读连接 / 空库 / 大表 |
| 10 | 越权入口不出现 | 用未授权许可证启动 |
| 11 | 快捷键是 Ctrl 系 | 菜单逐项看 |
| 12 | 文件对话框是 GTK 原生 | 打开一次 |
| 13 | 125% 缩放下边框不消失 | 改缩放重启 |
| 14 | 拖放有落点高亮 | 拖一个目录进窗口 |
| 15 | 终端中文不乱码、宽字符对齐 | `ls` 中文文件名 + `top` |

> 15 条里 1–7 是「第一眼」，8–15 是「用起来」。Linux 端此前被吐槽的主要是 1–7。
