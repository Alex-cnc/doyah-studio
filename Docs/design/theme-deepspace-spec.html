深空苍穹 · 主题实现规范

Doyah Studio · 视觉主题 · v1.0 · 2026-10-16 · 交付：铁皮大河马（实现方）
一句话目标：近黑四层景深 + 冷光微量点缀 + 发光只给焦点。
不是「更紫」——科幻的高级感来自 黑与微光，不来自彩色铺底。

一、为什么现有「星空紫」不达标

问题原因
显廉价科幻饱和紫大面积铺底 ⇒ 赛博朋克刻板印象；科幻感来自「黑 + 微光」
界面发闷、层次糊只有一层紫 ⇒ 侧栏 / 卡片 / 正文挤在同一明度上，只能靠加亮来救，越救越土
对比度难做紫底上正文发灰，深色主题的 AA 判据最先在这里翻车

二、令牌表（照抄即可）

① 深空底 · 四层景深

令牌值用途
bg.base#05070D窗口底（近黑，不用纯黑 #000）
bg.panel#0A0F1A侧栏 / 主容器
bg.card#111827列表项 / 浮动卡片 / 输入框
border.subtle#1B2436分隔线 / 描边

② 星云点缀（只做氛围，不做主体）

令牌值不透明度用法
nebula.violet#7C5CFF8~12%顶栏或左上角径向渐变
nebula.cyan#38BDF812%右下角径向渐变
nebula.magenta#F472B66%仅一处（制造纵深）

渐变只出现在边角或顶栏；禁止铺满（那是游戏启动页，不是工作界面）。

③ 主强调（交互 / 选中）

令牌值用途
accent.primary#5EEAD4选中 / 焦点 / 主按钮（等离子青）
accent.alt#60A5FA次强调 / 链接（等离子蓝）
accent.dimrgba(94,234,212,.14)选中行底 / 悬停底

④ 文字（深底上必须提亮）

令牌值对比度要求
text.primary#E6EDF7≥ 4.5:1（实测约 15:1）
text.secondary#94A3B8≥ 4.5:1
text.disabled#64748B≥ 3:1（禁用态可放宽但要能读）

⑤ 语义色（深底上提亮）

令牌值
state.success#34D399
state.warning#FBBF24
state.danger#F87171

⑥ 质感与动效

令牌建议值说明
effect.blurbackdrop-blur 20~30px侧栏 / 浮层 / 顶栏
effect.glow0 0 10px accent@35%只给焦点元素（选中 / 运行中）
effect.grid1px 线 · 不透明度 5~6% · 44px 栅格「舱内感」；不超过 2% 视觉强度
effect.border-grad1px 渐变（上亮下暗）顶栏下沿 / 卡片描边
motion.duration150~250ms禁常驻动画

三、实现落点（重要）

必须做成「一套令牌值」，不是新的代码路径。
家族已有主题令牌机制（星空紫等主题 = 同一套令牌的不同取值）⇒ 本主题应新增一组令牌取值， 走现有令牌注入链路；禁止为某个主题单写分支（否则四套主题各自写死 = 维护地狱）。

四、验收判据（可核，不是"看着好看"）

① 对比度读数：正文 ≥4.5:1 · 大字 ≥3:1；每个语义色在各自底色上复测（深色主题最常在这里翻车）。
② 无纯黑纯白存在（除强调元素）。
③ 全屏截图检查：发光只出现在焦点态（如活动栏选中 + 主按钮），别无他处发光。
④ 色板数量 ≤ 本节定义数（防止"改着改着变 40 个颜色"）。
⑤ 三点截图校验：主界面 / 侧栏 / 弹窗 —— 三处都要保持四层景深。
