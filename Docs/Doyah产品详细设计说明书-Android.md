## 1. 基线与禁止项

| 项 | 取值 | 说明 |
|---|---|---|
| 语言 | Kotlin（Multiplatform） | `core` 为跨端共享层，`app` 为 Android 外壳 |
| 构建 | Gradle（`gradle/` + wrapper） | `bench/` 为性能基准 |
| 判据 | `tools/`（含 `check-basis-coverage.py` 一类） | 与仓内 gate 一致 |
| 存储 | 本机 SQLite | 数据家在应用私有目录 |
| 网络 | 仅已授权的同步出口 | 私密条目与行数据永不出端 |

禁止项：禁止把 Android 专有 API 写进 `core/commonMain`（跨端层必须无平台依赖）；禁止为通过判据放宽 `commonTest` 断言；禁止私密条目进日志/导出。

## 2. 分层

| 层 | 目录 | 职责 |
|---|---|---|
| 共享能力层 | `core/src/commonMain` | 捕获、存储、检索、待办、私密规则（**无 Android 依赖**） |
| 平台实现 | `app/src/main` | 界面、通知、系统集成、文件访问 |
| 测试 | `core/src/commonTest`、`core/src/jvmTest` | 契约用例（JVM 可跑，无需真机） |
| 基准 | `bench/` | 性能读数 |

调用：`app` → `core`（单向）；**禁止** `core` 反向依赖 `app`。

## 3. 关键契约

### 3.1 捕获

- 后置：触发即进入可输入状态，无选择步骤；保存成功即本机可读；联网前状态是「待同步」而非「失败」
- 禁止：捕获路径出现必填的归属/模板/标签；空标题阻断保存
- 测试：`T-3.1-01`

### 3.2 附件

- 后置：库内只存引用；相同内容只存一份；显示操作不改原字节
- 禁止：字节入库；引用缺失画空框
- 测试：`T-3.2-01`

### 3.3 检索

- 后置：按 `Character` 偏移切分；命中不重叠；返回总数与首命中标识
- 禁止：utf8/utf16 偏移；联网检索
- 测试：`T-3.3-01`

### 3.4 私密

- 后置：私密条目在端内可见可用，出口（导出/分享/日志/同步）一律排除
- 测试：`T-3.4-01`

### 3.5 待办

- 后置：完成/重开/改期只走既有写入口，不新开写路径；日历与清单共用同一行渲染
- 禁止：界面自行计算日期（日期算术只在 `core`）
- 测试：`T-4.3-01`

### 3.6 归类（归属 = 笔记本）

- 后置：一条笔记唯一归属一个笔记本；未指定落默认收件箱；移动只改归属一列，不刷新内容更新时间、不产生内容版本
- 禁止：删本留下无归属条目；为「一处放两份」复制笔记；归属写成自由文本
- 测试：`T-3.6-01`、`T-4.4-01`

## 4. 数据与状态

- 库表：笔记本体 + 标签 + 时间线**同一事务**；待办与笔记同库。
- 正文权威源 = span 树；视图为投影，不一致按 span 树重投影。
- 自动保存：守卫（许可 / 有内容 / 有改动）缺一不写；`pending` 期间再编辑不丢键。
- 删除分级：条目进回收站；彻底清除需二次确认并判引用。
- 笔记本：`note_notebook`（端内旁挂表，与 `note_index` / `note_sync` 同侧）+ `note_index.notebook_id` 一列（默认收件箱 = 固定 id）；**单层**，不设父层
- 迁移：`ALTER TABLE note_index ADD COLUMN notebook_id TEXT NOT NULL DEFAULT '<收件箱固定 id>'` —— 与鸿蒙侧逐字一致（`check-schema-parity.py` 守）；不做第二份数据、不复制行
- 删本：`ON DELETE` 由显式事务决定 —— 二选一（笔记进回收站 / 改挂默认收件箱），默认收件箱行只读

## 5. 界面

| 视图 | 必须呈现 | 禁止 |
|---|---|---|
| 笔记列表 | 分区、条数、私密标记 | 同步令牌 |
| 正文编辑 | 保存态、附件引用 | 空框 |
| 待办清单 / 日历 | 完成、改期、档位徽标 | 界面自算日期 |
| 搜索 | 命中高亮、总数 | 联网结果 |
| 笔记本（分类入口） | 笔记本列表 + 全部 / 未归类 / 某本三种范围 + 条数 | 无归属条目；进列表才让选本 |

六态齐（加载/空/错误/权限不足/提交中/部分失败）。

## 6. 错误

| 类别 | 呈现 | 禁止 |
|---|---|---|
| 库不可写 | 说明 + 重试 | 静默丢内容 |
| 附件缺失 | 原名与原位置 | 空框 |
| 同步失败 | 「待同步」而非「失败」 | 把网络不可用报成保存失败 |

## 7. 非功能

- 离线可用为硬约束；无网无账号全功能可用。
- 性能：万条笔记下列表与搜索首屏可交互；`bench/` 给读数。
- 权限：只申请必需的存储/通知权限；拒绝后功能降级但可读。
