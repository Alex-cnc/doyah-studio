## 1. 基线与禁止项

| 项 | 取值 | 说明 |
|---|---|---|
| 语言/框架 | 与公司机器既有工具链一致（本文件不指定，实现时在同一基线内） | 一旦定下即进本节，改需批准 |
| 存储 | 本机 SQLite（笔记数据家） | 独立目录，不写进工程数据家 |
| 网络 | **零出口** | 不同步、不遥测、不调用任何远端 |
| 账号 | 无（单人本机） | 不出现登录、不同步 |

概设中的禁止项在本端落到最严：禁止云同步、禁止遥测上报、禁止把笔记正文写进日志、禁止私密条目进入任何导出包。

## 2. 分层

| 层 | 职责 |
|---|---|
| 界面层 | 列表 / 正文 / 搜索 / 保存态；不算业务规则 |
| 能力层 | 捕获、存储、检索、私密、回收站；唯一写库处 |
| 平台接入 | 文件系统、剪贴板、快捷键 |

调用：界面 → 能力 → 本机存储；**禁止**界面直写库、禁止能力层发起网络。

## 3. 关键契约

### 3.1 捕获与保存

- 前置：无（捕获路径不得有必填项）
- 后置：写入本机即成功，立即可读；空标题不阻断，取正文首行；首行为空显示「无标题」
- 禁止：捕获前要求选归属/模板/标签；把「待同步」当失败显示
- 测试：`T-3.1-01`

### 3.2 附件

- 前置：文件可读
- 后置：库内只存引用（标识/原名/字节数/摘要）；相同内容只存一份；原字节在任何显示操作后摘要不变
- 禁止：把附件字节写进库；改写原件；引用解析不到时画空白框
- 测试：`T-3.2-01`

### 3.3 检索

- 前置：查询串可为空（空即列出全部）
- 后置：命中按 `Character` 偏移切分（中文不错位）；命中不重叠；返回总数与首个命中标识
- 禁止：按 utf8/utf16 偏移切分；联网检索
- 测试：`T-3.3-01`

### 3.4 私密与出口

- 后置：私密条目在列表可见、在**任何导出/分享/日志**里不出现
- 禁止：私密条目进入导出包、日志、崩溃报告
- 测试：`T-3.4-01`

## 4. 数据与状态

- 存储：本机 SQLite；正文权威源是 span 树，正文视图是投影；投影与正文不一致按 span 树重投影，不反向写。
- 数据家：笔记目录与工程数据家**平级独立**；迁移原子写 + 校验。
- 删除分级：删条目只让引用失效（进回收站）；彻底清除才判引用并二次确认。
- 自动保存：合并窗口与守卫（许可 / 有内容 / 有改动）缺一不写；`pending` 期间再编辑保持 pending 并重排，不丢新按键。

## 5. 界面

| 视图 | 必须呈现 | 禁止 |
|---|---|---|
| 列表 | 分区、条数、私密标记 | 显示同步令牌 |
| 正文 | 编辑区、保存态、附件引用 | 空框占位冒充附件 |
| 搜索 | 命中高亮、总数 | 联网结果混入 |
| 空态/错误 | 说明 + 下一步 | 空白页无说明 |

六态齐；禁止只做正常态。

## 6. 错误

| 错误类别 | 呈现 | 禁止 |
|---|---|---|
| 库不可写 | 明确说明与位置 + 重试 | 静默丢内容 |
| 附件缺失 | 「文件不在了」+ 原名与原位置 | 空白框 |
| 迁移失败 | 保留原文件 + 可读原因 | 用默认值覆盖 |

## 7. 非功能

- **零网络出口**：判据 = 依赖与系统调用扫描（禁止 socket/HTTP 客户端依赖）。
- 离线可用：无网无账号下捕获、保存、检索、打开全部可用。
- 性能：万条笔记下列表与搜索首屏可交互。
