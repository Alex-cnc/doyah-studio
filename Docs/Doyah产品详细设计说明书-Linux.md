## 3. 关键契约

### 3.1 连接（§4.1/§4.2）

- 前置：`dbType` ∈ {postgresql, mysql, gbase8a}；host 非空；port 1…65535
- 后置：返回句柄与生效库名；凭据只进密钥存储，不回传界面
- 禁止：口令进日志/导出/模型上下文；删除连接留残留凭据
- 测试：`T-3.1-01`

### 3.2 执行与取消（§4.3/§4.4）

- 后置：按文本顺序逐条；多结果集全保留；事件流 `started → resultSet×N → finished | cancelled | failed`
- 取消：服务端真取消，连接仍可用，之后不再收结果集
- 禁止：写语句自动重试；失败报成功；只停界面
- 测试：`T-3.3-01` / `T-3.3-02`

### 3.3 元数据（§4.5）

- 层级按数据库类型给出（服务器 → 库 → schema（如该类型有）→ 表/视图 → 列）；刷新不清选中
- 禁止：把不同方言层级强行统一；伪造占位节点

### 3.4 结构变更与导入导出（§4.7/§4.8）

- 结构脚本**先预览后执行**；删表类二次确认；导入目标已存在必须询问；部分失败逐项列出
- 禁止：未预览执行 DDL；静默覆盖目标；导出含凭据

### 3.5 服务器会话（§4.9）

- 列会话四项读数；取消语句 / 终止会话分别入口；终止需二次确认并说明「掐断连接、回滚未提交」

### 3.6 助理上下文（§4.10）

- 只投文本与标识；含结果行数据必须显式确认并留痕
- 禁止：默认投递行数据；让助理绕过审批执行写操作

### 3.7 命令行出口（§19.1）

- 单进程、无界面依赖、无 TTY 必须非交互
- 参数来源优先级：显式开关 > `PG*` 环境变量 > 已保存连接
- 退出码：连接失败 `1` / 查询失败 `2` / 对象树失败 `3`；错误只进 stderr
- 禁止：口令入参/入历史/入日志；失败返回 0

### 4.3 查询全链（对应概设 §7.1）

界面取显示中编辑器 → 选区判定 → 只读/高危判定 → 执行 → 逐条回报 → 渲染 + 写历史 → 审计一条。

### 4.4 状态机

四台（连接 / 执行 / 审批 / 页签）同概设 §6；禁止新增状态、禁止绕过 guard；非法流转返回错误，不静默。

## 6. 错误映射

21 个错误码逐码落点：`CONN_*`（四类 + 无凭据 + 清理失败）、`EXEC_*`（空 SQL / 未连接 / 只读拒写 / 需确认 / 服务端错 / 链路断 / 取消非法）、`META_UNSUPPORTED`、`DATA_*`、`DDL_*`、`IO_*`、`SESS_*`、`LIC_NO_CAPABILITY`。四条禁止兜底同等生效；日志禁记口令与结果行数据。

## 7. 并发与安全

- 一个「连接 + 库」一个服务实例；同连接语句串行；取消走句柄。
- 笔记写入单事务；私密条目零外发。
- 鉴权在能力层与驱动层，禁前端-only；注入防护一律参数化。
- 运行约束：单机、离线可用（模型与授权同步除外）；配置只读自三处真源。

## 9. Notes 在 Linux（`FR-STD-ALL-PLUG-005`）

### 9.1 离线装配

- 随包引入笔记模块，活动栏有入口；数据只落本机 SQLite（独立数据家）。
- **进程内零网络出口**：不同步、不遥测、不调用云端服务。判据 = 依赖与系统调用扫描（禁 socket / HTTP 客户端），每轮复跑。

### 9.2 捕获与保存

- 触发即编辑，无选择步骤；空标题不阻断（取正文首行，空则「无标题」）；断网可记，状态为「待同步」而非失败。

### 9.3 附件与检索

- 库内只存引用，相同内容一份，原字节不改写；引用缺失报「文件不在了」。
- 检索覆盖标题/正文/标签；中文需 trigram 分词（`P-15`），查询串 <3 字按子串兜底并**如实标注走了哪条路**；「没跑成」不得显示成「没找到」。

### 9.4 私密与回收站

- 私密条目端内可用，任何出口（导出/日志/崩溃报告）排除；删除进回收站，彻底清除二次确认。

### 9.5 与 Studio 的边界

- 笔记数据家与工程数据家**平级独立**；宿主只单向传上下文（文本与标识），行数据须确认并留痕。
