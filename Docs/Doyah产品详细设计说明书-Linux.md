## 0. 引用规则（先读这一页）

### 0.1 三条规则

1. **默认照 macOS**：能力相同、需求相同、概设相同，所以 macOS 详设 §2–§9 的契约对本端**直接生效**，包括错误码
   （`CONN_*` / `EXEC_*` / `DATA_*` / `DDL_*` / `IO_*` / `SESS_*` / `META_*`）、禁止项（不拼 SQL、不隐式转换、
   不用关闭连接实现取消、不把行数据未确认投给 Agent…）、并发约束（一连接串行、一批一事务、长任务进阻塞线程池）、
   日志口径（禁记口令与正文）、测试 ID（`T-3.x-xx`）。
2. **本书只写差异**：差异必须落到「哪一处不同 + 依据 + 本端落点」。不产生差异的节，本书一个字都不占。
3. **不许抄**：把 macOS 正文搬过来就是两处维护、必然漂移（历史上「英文行夹汉字」「两本书说法不一致」都是这么来的）。

## 1. 平台差异（逐条给契约）

### 1.1 凭据：`SecretStore`（替代 macOS 的 Keychain 访问）

| 项 | 契约 |
|---|---|
| 落点 | `Platform/linux/src/secrets.rs`（真绑定：`secret-service` D-Bus） |
| 接口 | `get(service, account) -> Result<Option<String>>` · `set(...)` · `delete(...)` · `is_available() -> bool` · `backend_name() -> &'static str` |
| 前置 | 服务名与账号稳定；密钥只从 stdin / 0600 文件进 |
| 后置 | 写入可跨重启恢复；`delete` 对不存在条目返回成功（幂等）；`is_available()` 为假时**所有写操作直接失败**，绝不回落明文 |
| 失败 | 无密钥环 → `CONN_NO_CREDENTIAL`（配置页给可读补救指引）；D-Bus 拒绝 → 原话上浮；条目已存在 → 覆盖而非报错 |
| 禁止 | 写明文兜底文件；把密钥回显给界面；在日志里打印长度以外的值 |
| 日志 | `service`、`account`、`backend`、`result`；值一律不记 |
| 测试 | `T-1.1-01`（无密钥环时写失败且无明文落盘）、`T-1.1-02`（写入→重启→可读）、`T-1.1-03`（重复 delete 幂等） |

### 1.2 路径：XDG 三区

| 类别 | 路径 | 内容 |
|---|---|---|
| 配置 | `$XDG_CONFIG_HOME/doyah-studio/`（缺省 `~/.config`） | `connections.json`、`appearance.json`、`agent.json` |
| 数据 | `$XDG_DATA_HOME/doyah-studio/`（缺省 `~/.local/share`） | `queries/`、`chat/`、`agent-undo/`、`agent-audit.json`、`saved-queries.json`、`retro/` |
| 缓存 | `$XDG_CACHE_HOME/doyah-studio/` | 可丢弃的派生数据 |

- 目录权限：配置与数据 0700；含凭据引用的文件 0600。
- `paths::app_home()` 是本端唯一的路径出口，界面与命令层**不许手拼**环境变量。
- 环境变量缺失时按 XDG 缺省值展开；**不许**回落到当前工作目录。
- 测试：`T-1.2-01`（三区各归其位）、`T-1.2-02`（变量缺失按缺省展开）、`T-1.2-03`（文件 0600、目录 0700）

### 1.3 窗口与装饰

- 用**系统标题栏**，不自绘；窗口最小 **1120 × 720**，低于此折叠侧栏。
- 三栏：活动栏 46 → 侧栏 248（可拖到 420）→ 主区；工具栏 44、状态栏 24 贯穿整窗。
- 系统装饰下不做「红绿灯」替代物；关闭行为按桌面环境默认，应用只拦「有未保存页签」。
- 测试：`T-1.3-01`（最小窗下三栏不重叠、状态栏可见）

### 1.4 字体与缩放

| 用途 | 回退链 | 字号 / 行高 |
|---|---|---|
| 界面 | `Inter` → `Noto Sans` → `Source Sans 3` → `Noto Sans CJK SC` → `sans-serif` | 12 / 18 |
| 等宽 | `JetBrains Mono` → `Noto Sans Mono` → `Noto Sans Mono CJK SC` → `DejaVu Sans Mono` → `monospace` | 12 / 20 |

- 回退链必须显式写全（不写就落到 DejaVu / 文泉驿，中英混排字形跳变）；等宽缺 CJK 回退 ⇒ 终端中文变方框。
- 字重只用 400 / 600；DPI 按 `devicePixelRatio` 取整到 1 px；图标用 SVG 或 2x 位图。
- 测试：`T-1.4-01`（中英混排无跳变）、`T-1.4-02`（125% 下 1 px 边框不消失）

### 1.5 文件对话框、通知、托盘、拖放、终止确认

| 面 | 契约 | 禁止 |
|---|---|---|
| 文件对话框 | GTK FileChooser（Tauri dialog 插件），记住最近目录 | 自绘选择器 |
| 通知 | D-Bus / libnotify；服务缺失降级为窗内提示 | 静默丢 |
| 托盘 | 有则提供「显示主窗口 / 退出」；无托盘不阻塞启动 | 无托盘就不让退出 |
| 拖放 | 文件拖入 = 打开，目录拖入 = 切换工作区，落点高亮 | 拖进来无反馈 |
| 会话终止 | 终止前二次确认并说明后果（macOS §3.13 之外多这一道） | 默认勾选确认 |

- 测试：`T-1.5-01`（GTK 对话框 + 记住目录 + 终止需确认）、`T-1.5-02`（无通知服务时窗内提示）

### 1.6 快捷键映射

| 动作 | macOS | Linux |
|---|---|---|
| 保存 / 全选 / 查找 | ⌘S / ⌘A / ⌘F | `Ctrl+S` / `Ctrl+A` / `Ctrl+F` |
| 命令面板 | ⌘⇧P | `Ctrl+Shift+P` |
| 快速跳转 | ⌘K | `Ctrl+K` |
| 关闭页签 | ⌘W | `Ctrl+W` |

- 菜单里显示的就是实际按键；`Cmd` / ⌘ 字样不许出现在 Linux 界面。
- 测试：`T-1.6-01`（菜单文案与实际按键一致、无 ⌘ 残留）

### 1.7 终端：真 PTY

- `probe_pty` 判定可用性；打开后是真交互式 shell，**不是**日志面板。
- 关闭必须释放子进程；输出超上限按窗口截断并标记；宽字符与颜色由前端渲染。
- 失败：无 shell → `SHELL_MISSING`；句柄不存在 → `TERM_NOT_FOUND`（不自动重开）。
- 测试：`T-1.7-01`（真回显）、`T-1.7-02`（关闭无孤儿进程）、`T-1.7-03`（超长输出标记截断）

### 1.8 构建与分发

- 入口 `Platform/linux/build.sh`：宿主不是 Linux → 退出码 **2**；同源前端缺失 → **4**；成功出 deb / AppImage。
- 图标同一品牌图形；身份四项（目录、标签、sha256、构建时刻）随包走。
- 测试：`T-1.8-01`（非 Linux 宿主如实拒绝）、`T-1.8-02`（缺前端即拒）、`T-1.8-03`（产物身份卡与包内一致）

### 1.9 权限模型

- `capabilities/default.json` 只放实际用到的权限（文件对话框、通知、终端、密钥环）；新增权限先进允许清单再动配置。
- 被拒时给可读原因，不静默失败。
- 测试：`T-1.9-01`（权限清单最小集）、`T-1.9-02`（被拒有可读原因）

## 2. 本端独有面（macOS 没有对应物）

> 这几件是 Linux 端启动与自检要用的东西，macOS 用别的手段解决，没有可引用节，只能在这里写。

### 2.1 能力探测（九个探针）

| 函数 | 输出 | 失败语义 |
|---|---|---|
| `probe_all() -> Vec<CapabilityProbe>` | 全部探针结果（保序） | 单个探针失败不许终止整体 |
| `probe_webview()` | WebView 运行时是否可载 | 缺失 → 启动给补救指引 |
| `probe_secret_service()` | 密钥环可达性 | 缺失 → 凭据入口禁写 |
| `probe_pty()` | PTY 可用性 | 缺失 → 终端入口不出现 |
| `probe_notifications()` | 通知服务 | 缺失 → 窗内提示降级 |
| `probe_clipboard()` | 剪贴板 | 缺失 → 复制动作给可读失败 |
| `probe_tray()` | 托盘 | 缺失 → 不阻塞启动 |
| `missing(probes)` | 缺失项集合 | 空 = 全部可用 |
| `capabilities() -> Vec<CapabilityDto>` | 给界面的能力位 | 只暴露布尔与原因码 |

- 探针**只读**宿主状态；同一进程内缓存一次。
- 测试：`T-2.1-01`（缺失项如实报）、`T-2.1-02`（单探针失败不影响其他）

### 2.2 可用性三态与身份卡

| 函数 | 契约 |
|---|---|
| `Availability::parse(raw) -> Self` | 闭集三态（可用 / 缺失 / 未知）；未知串 → 未知，不 panic |
| `Availability::as_str()` | 稳定字面量，界面与日志共用 |
| `ArtifactIdentity::new(dir, label, sha256, built_at)` | 四项缺一即 `IdentityError`；sha256 必须 64 位十六进制 |
| `ArtifactIdentity::identity_card()` | 人读卡片，字段顺序固定 |

- 测试：`T-2.2-01`（未知串不 panic）、`T-2.2-02`（缺项报 `IdentityError`）、`T-2.2-03`（卡片字段顺序稳定）

### 2.3 CLI 与启动

| 函数 | 契约 |
|---|---|
| `main() -> ExitCode` | 无参 = 起壳；`capabilities [--json]` = 报告；未知参数 → 用法 + 非零退出 |
| `report_capabilities(json: bool)` | JSON 模式字段名固定；文本模式给人读 |
| `startup_report() -> StartupReport` | 起壳前自检汇总；**缺承载面必须非零退出**，不白屏 |
| `run()` | 起壳；承载面缺失 → 非零退出并给补救指引 |
| `paths::app_home()` | §1.2 唯一路径出口（只读引用同源实现） |
| `doyah_studio_shell::attach(builder)` | 挂同源命令层；**本端不另长一份命令实现** |

- 测试：`T-2.3-01`（未知参数非零退出）、`T-2.3-02`（缺承载面非零退出且有指引）、`T-2.3-03`（`--json` 字段名稳定）

## 3. Agent 面差异

### 3.1 语义照 macOS §3.14–§3.30，本端只改落点

| 面 | 本端落点 | 与 macOS 的差别 |
|---|---|---|
| 对话流式 | `agent_generate::chat_stream_with_carry(store, turns, pending, carry, sink)` | 同源；门未开返回 `ChatReply::Blocked`，不是 `Err` |
| 工具回灌 | `agent_generate::chat_tool_resume(...)` | `calls` 与 `approvals` 条数不等即拒发；拒绝也回灌 |
| 写盘预览 / 撤销 | `write_preview` / `resolve_write_target` / `undo_write` | 预览与落盘同一份路径校验；内容哈希不符拒撤 |
| 分类与审批 | `agent::{classify, risk_points, decide, Approval}` | macOS 是 Swift 闸；本端用同源状态机 |
| 预算 | `agent::Quota` | 次数与 token 双上限，耗尽即停 |
| 注入防护 | `agent::{wrap_untrusted, redact}` | 行数据未经确认不投 |
| 配置门 | `agent_config::evaluate` | 缺密钥与端点非法分开报；公网明文一律非法 |
| 会话 / 审计 | `agent_chat_session::*`、`agent_audit::*` | 落 §1.2 数据区；审计追加、可导出、不含正文 |
| 对话区步数 | 同源前端 | 步数分母 = 本次运行总上限；详单有最大高度 + 内部滚动 |

## 6. 本端已知坑（动工前必读）

1. **没有密钥环的发行版**（部分容器 / 极简 WM）：`SecretStore` 不可用，凭据一律写不进去 —— 这是**如实失败**，不要临时加明文兜底。
2. **WebKitGTK 版本差异**：老版本不支持的部分 CSS（`backdrop-filter` / 容器查询）会静默退化，验收要按目标发行版实测。
3. **字体缺失**：未装 Noto CJK 时中文落到文泉驿，宽度与字重都变 —— 打包依赖里要带字体或给安装提示。
4. **托盘在 GNOME 默认不存在**：需要扩展才有；托盘缺失必须不阻塞启动（§1.5）。
5. **自绘标题栏在 KDE 上会盖住系统按钮** —— 本端明令不自绘（§1.3）。
