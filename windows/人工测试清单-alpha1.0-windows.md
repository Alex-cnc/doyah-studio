**本版明确不做**（不是缺陷，是范围；出包时按实际交付面逐条核对）：

- **MySQL / GBase 连接**：数据库侧已按人类主入口径"放下"，本版只做 PostgreSQL。
- **TLS（`require` / `verify-*`）**：未接线；选这三档会**明确报"未接线"**，**不静默降级成明文**。
- **多语句一次执行**：`prepare` 只接受单条（一次执行一句）。
- **主题下拉 / 星云皮肤**：本版没有（按"一版一模块"，外观属 Workspace 段）。
- **签名 / 公证 / 商店分发**：自用口径不需要。
