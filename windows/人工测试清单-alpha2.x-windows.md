# Doyah Studio · Windows 版 · 人工测试清单（alpha 2.x = Workspace）

> 口径 = 跨仓交付纪律（`Docs/发布计划.md` §5 第 1 条）：**每个 alpha 交付随包附一份「需要人工测试的清单」**。
> **只列机器测不了的人工面** —— 机器能验的已经写进机械判据（`windows/Tools/verify-all.ps1` 15 项 + `cargo test` **246 例** + `vitest` **184 例**），本清单不重复收。
> 由 **黄鳍大肥鱼（`fatfish` / Windows 侧）** 出，随 2.x 的包同时交；与 alpha 1.0 那份**分开**（模块不同）。

**本版明确不做**（不是缺陷，是范围；出包时按实际交付面逐条核对）：

- **权限 / 属性编辑**（自用口径，计划已定"不做"）。
- **用户自定义主题编辑器**（计划已定"不做"）。
- **插件市场 / 远端同步**（计划已定"不做"）。
- **代码格式化（2.6）**：**形态待人类主人拍板**，本版未做 —— 计划要求"不支持要如实说"，界面上也不给入口。
- **内置终端（2.7）**：领域层三笔已落，但**ConPTY 落地卡住**（实测"子进程不执行命令"，已回退不留残缺代码）⇒ **本版不给终端入口**，等拍板后再做。
- **智能体接面（2.9 的一半）** 与检索里的「笔记」那一类：笔记属 3.x，且计划 3.7 已定"Windows 版 Notes 当前不在投入面"。
