## 一之二、这一版的界面改了什么（按老板给的两张 macOS 封面图）

| # | 改的地方 | 做了什么 |
|---|---|---|
| 1 | **底部面板** | 新增「问题 / 输出 / 终端 / 调试控制台」四格；输出与问题**真能收东西**（视图回执喂进来，有上限）；可折叠 |
| 2 | **Home 页三栏** | 最近打开的文件 / 最近打开的工作区（**当前那个打勾**）/ 连接；**没连过库就不画连接那一栏**（不留空栏位充数） |
| 3 | **数据库左栏** | 连接列表**带分组**（未分组的归"未分组"且排最后）、每条**两行**、**当前连着的那个高亮**；对象树加**「层级视图 / 按类型分组」**两个切换 + 搜索 + 刷新 |
| 4 | **SQL 区** | **查询页签**（「查询 1 ×」+ 加号；每个页签各自一份 SQL；最后一个不给关）；工具条加**「库」下拉**与**「清空」** |
| 5 | **标题栏搜索** | 接**全局搜索**：回车/点一下 ⇒ 开命令面板并带词（复用面板已有的命令 / 文件 / 对象三合一搜索） |

### 三处"我故意没做"的（是范围或能力所限，不是坏了）
1. **内置终端（2.7）没给入口**：真起 shell（ConPTY）那一半没打通 ⇒ 终端那格点进去**如实写"未开工"**，
   **不拿半成品充数**。领域层三笔（屏幕模型 / 按键粘贴编码 / 页签会话，**29 例判据**）在库。
2. **没有 SQL「格式化」按钮**：核过领域层，**本侧没有 SQL 格式化能力** ⇒ **不放假按钮**。
3. **「库」下拉列的不是服务端全部库**：本侧没有"列库"命令 ⇒ 它给的是
   **已保存连接里同主机同用户的那些库**，选一个 = **重连到那个库**（提示里写明了）。

## 二、这一段能做什么（按模块）

| 模块 | 能做什么 |
|---|---|
| 工作区骨架（2.0） | 打开文件夹、Explorer（忽略名单与隐藏项是**两个维度**）、按需展开、键盘走位、Home 页、窗口标题随活动栏、标题栏居中搜索 |
| 文件操作（2.1） | 新建 / 重命名 / **删除走回收站**（非空文件夹二次确认）/ 拖拽移动（**自吞被拒**）/ 在资源管理器（**选中文件**）与终端打开 |
| 编辑面（2.2） | 多语言高亮、行号列（列宽按字体实量）、**六种换行符都认** |
| 页签与会话（2.3） | 多页签、重启后**页签与光标回来**、**按类型打开**（图片按内容认、二进制与过大如实说）、**保存冲突拒绝而不覆盖**、外部改动如实说 |
| 检索与替换（2.4） | 文件名 / 内容两种检索（**共用一处引擎**）、点命中跳行并**标出命中内容**、**跨文件替换先预览影响面**、跳过分类如实显示 |
| Markdown（2.5） | 只读预览（一份解析、渲染树里无可编辑控件）、可切源码 |
| 代码格式化（2.6） | **外部工具优先**（说得清用了哪一个与版本）；没有则**内置兜底并如实说明**；内置两档只动空白，**字符串/注释里的空白一个字不动** |
| 外观（2.8） | 深浅轴 × 配色轴正交、跟随系统不重启、**星空紫星云皮肤** |
| 面板与历史（2.9） | 命令面板（清单↔分派器↔视图**三者对账**）、全文检索（文件 / 数据库对象）、**常用命令排前面**、清空使用记录 |

## 三、明确不做（是范围，不是缺陷）

- **权限 / 属性编辑**、**用户自定义主题编辑器**、**插件市场 / 远端同步** —— 计划已定"不做"。
- **内置终端（2.7）**：领域层三笔已完成（屏幕模型 / 按键粘贴编码 / 页签会话，**29 例判据**），
  但**真起 shell 那一半没打通** ⇒ **本版不给终端入口**（不拿半成品充数）。详见 `版本计划.md` §5.3。
- **智能体接面（2.9 的一半）** 与检索里的「笔记」那一类：笔记属 3.x，且计划已定
  「Windows 版 Notes 当前不在投入面」。
