## 本批改动

1. **`Core/HighRiskTaskApproval.swift`（新）**
   - `plan(sql:targetDatabase:databaseType:)` 用**执行侧同一个** `StatementSplitter` 拆句（不另写正则），
     再 `plan(statements:targetDatabase:)` 把每条包成 `Statement{index 1 起, sql, kind 首词, targetDatabase, impact}`；
   - `Impact` 三档：`pending` / `rows(N)` / `unavailable(原因码)` —— **缺省是 `pending`，不是 `rows(0)`**；
   - `outcome(for:decision:)` 是唯一决策口：`.approve` ⇒ `.sendAll(整批原序)`，`.reject` ⇒ `.sendNothing(reason:"rejected")`
     （「未确认不发送任何语句」是结构性的）；
   - 计划身份 `fingerprint` = FNV-1a 64（目标库 + 每条原文 + **语句边界分隔符**；不用 `Hasher` 的随机种子）；
   - 本文件**零中文字面量**（Core 汉字棘轮不因它增长）。
2. **审批单接成逐条呈现**（`App/Views/AgentApprovalSheet.swift`）：`#序号 · 类别` / `目标库: X` / 这条自己的「≈N 行」/ 原文；
   多条时**不再显示整批合计**（合计会把「其中一条扫全表」摊平），单条时口径与原来一字不差（回归面保留）。
3. **`App/AppState.swift`**：`highRiskPlan(for:)` + `estimateHighRiskPlan(_:)`（逐条各问一次优化器）；
   `decideAgentAction` 用 `outcome` 的 `sendsAnything` 决定「发还是不发」（计划建不出来时退回人点的那个选择）。
4. **拒绝状态独立**（`Core/DataTask.swift` + `AgentPresentation` + `AgentSchedulePresentation` + 语言表）：
   新增 `TaskRunRecord.Status.rejected`（「已拒绝」/ `Rejected`，橙色 `hand.raised.fill`），
   拒绝走新的 `rejectDataTaskRun`，`skipDataTaskRun` 删除（`skipped` 只剩历史兼容）。
