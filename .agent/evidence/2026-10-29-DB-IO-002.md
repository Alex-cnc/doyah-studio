## 1. 做了什么

### Core（纯判定，不碰 IO）`Core/TableExport.swift`

- `selectSQL(table:schema:dialect:)`：`SELECT * FROM <限定名>`，**不加 `ORDER BY`** —— 为顺序排一次要把全量读进内存，
  正好毁掉流式；口径落进账（`orderGuaranteed = false` 时报告里带一句「行序不保证与网格一致」）。
- 标识符只拒**结构性非法**（空名、含 `\0`），**不用 `PrivilegeProbe.isValidIdentifier`** —— 它要求首字符是字母 /
  下划线，会把 `My Table`、`order items` 这类合法引用名一起拒掉。注入面靠引号转义挡住，判据钉住（见 §2）。
- `entries(schema:tables:format:)`：整库落点。表名 → 文件名的净化（路径分隔符 / 控制字符 / 空白换掉、保留 Unicode、
  `..` 与点开头兜底、超长截到 120）＋ **净化后撞名顺延 `-2`**（不许静默覆盖，覆盖等于少导一张表而账上说成功）。
- `Ledger` / `Receipt`：逐表结局。成功与没成分开；**没成的表即使取到过行也不并进总行数**（那是没有可交付成果的读数）；
  `report(labels:)` 是验收要点 ④「完成后报告行数与文件路径」的唯一出处。
- `streamingSupported(_:)`：服务端游标只有 PostgreSQL 有（`CursorPaging` 生成的是 `BEGIN` / `DECLARE` / `FETCH` / `CLOSE`）。

### App（接线）

- `AppState.exportTable(_:format:)`：NSSavePanel → `CursorPaging.plan` → `CursorFetcher` 逐页取 → `ResultStreamWriter`
  逐页写 → 小结。取数与写盘**复用既有那对 Core 类型**（与 CLI `export --table` 同一条路，同一份文件产物口径）。
- 同批把「执行一条不回结果集的语句」的循环抽成 `runTakingLastResultSet` 一处 —— 流式结果集导出原来自己写了一份，
  两处各写一份迟早一处改了另一处没改（空页 / 空结果集口径最先分叉）。
- `App/Views/TableExportSheet.swift`：小结面板（进行中「已取 N 行（N 页）」→ 完成「N 行 → 路径」→ 失败「没导出成（原因）」）。
  挂在 `ConnectionListView` 的 sheet 宿主上（对象树动作没有页签，`reportTabStatus` 与全局状态栏都挂不到这条链）。
  用 `isPresented` + 读 `tableExportSummary` 而不是 `sheet(item:)`：进行中会中途更新文本，`sheet(item:)` 拿的是呈现那一刻的值。
- `ObjectTreeContextMenu`：表 / 视图行 → 「导出整表…」→ CSV / TSV / JSON / Markdown / INSERT 五档。
  **xlsx 不进这个入口**（`ResultStreamWriter` 对二进制格式本来就抛 `binaryFormatNeedsFullResult`）。
- 语言表 +13 键中英齐。

## 4. 已知限制与仍差（都如实登记，没有一条假装完成）

1. **整库导出的界面入口**：Core 的名单与账（`TableExport.entries` / `Ledger`）已备，右键 schema / database → 选目录 →
   逐表落文件这一层下一批接（一轮内做不完两件事，先交付能端到端跑通的那一半）。
2. **MySQL / GBase 没有服务端游标** ⇒ 整表导出今天只对 PostgreSQL 开；入口按 `streamingSupported` 拦并指路
   「先 `SELECT * FROM 表`、再导出结果集」—— 不摆一个点了必然失败的按钮，也不拿「整份读进内存」冒充流式。
   （CLI 的 `export --table` 今天**没有**这道判：在 MySQL 上它会拼出 PG 语义的游标语句然后失败。属 CLI 侧的缺口，
   本批不动它 —— 记在这里，别让下一个人以为两边一致。）
3. **`COPY … TO STDOUT` 仍不可用**：见 §0，属 R-036 已知限制；要动就改 Vendor 驱动状态机，单列排期。
4. **敏感列排除**：需求否定面写着「不含敏感列除非你显式勾选」，而「哪些列算敏感」没有口径（凭列名猜 = 造一张迟早错的
   名单）⇒ 今天一条都不排除，账里也没假装排除。**待主人拍板**。
5. **整表导出暂不记执行回执**：`ExecutionReceipt` 挂在查询页签上，这条链没有页签。
6. **人工点验三项**：导一张表看小结与文件 / 导十万行以上的表看内存 / 空表应读「没有行、没生成文件」。
