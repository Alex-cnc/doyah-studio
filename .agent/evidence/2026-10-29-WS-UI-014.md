## 2. 落法

**Core（口径一处）** `Core/DialogButtonPolicy.swift` —— 把一份动作声明投成「该画的那一行」：

- `DialogActionSpec`（id / title / systemImage / role / isEnabled）+ `DialogActionRole` 四档（cancel · neutral · primary · destructive）；
- `resolve(_:dismissible:)` → `DialogActionLayout`：`accepted` / `rejected` / `defaultActionID` / `cancelActionID` / `violations`；
- 三条会掉进去的口径：① **次序是排出来的**（cancel 最左 → neutral → destructive → primary 最右；破坏性动作永远不是回车）；
  ② **纯图标是被拒，不是被修**（给它自动补一句文案 = 让编译期猜语义；`visibleTitle` 走 trim，`" "` 也算纯图标）；
  ③ **同名两条也是违规**（两枚「保存」在截图与读屏里无法区分）；
- 违规五档各带涉事 id，另有机器码（`dialog.action.*`）。

**界面（动作行一处）** `App/Views/DialogActionRow.swift` —— 一行只填声明，画什么由 Core 投影决定：
`role == .cancel ⇒ ButtonRole.cancel`、`primary ⇒ keyboardShortcut(.defaultAction)`、`cancel ⇒ .cancelAction`；
没给图标时按档位补一枚（`fallbackSystemName(for:)`）。

**接线（21 + 5 个文件）**：

- 三条代表性对话框改走 `DialogActionRow`：`CreateDatabaseSheet`（取消 + 主按）、`SaveQuerySheet`（两行：保存 + 跳转行）、
  `DropDatabaseSheet`（取消 + **破坏性**，手工输库名那条 `isEnabled` 判定原样搬进 spec）；
- 取消 / 关闭 / 稍后类动作补 `role: .cancel`：脚本按「`DialogActionButton(... title: L(.commonCancel|commonClose|safetyConfirmCancel|relaunchLater))`」
  与「`Button(L(.commonX))`」两种写法改，**21 个文件**（`~/.hermes/cache/scratch/fix_dialog_roles.py`）；
- 两处纯图标菜单补文字：`AgentSettingsSheet`（`Label(L(.agentModel), systemImage: "chevron.up.chevron.down")`）、
  `DataTaskPanel`（`Label(L(.dataTaskUseStoredDirectory), ...)` —— 文案取那一句原话，不另编）。

## 6. 口径取舍（本片自己的判断，留给后来人）

1. **纯图标「拒」而不「补」**：给空标题自动补 `systemImage` 那句英文是让编译期猜语义，且英文会绕过语言表。
2. **次序固定为 cancel → neutral → destructive → primary**：破坏性动作紧邻主按之前（回车不会落到它），
   而「右侧最后一枚是回车」这条在 macOS 上是可预期的。
3. **`dismissible` 是参数而不是恒真**：只有不可关的行（例如向导里的「下一步」）才允许没有取消；
   默认 `true`，因为一条能被 Esc / 关窗关掉的对话框**必须**有一枚说得出口的取消。
4. **源树判据扫 `*Sheet*.swift` 而不是扫全部 `App/Views`**：`*Panel*` 里多数动作是工具条式的（横向空间被文案挤压，
   纯图标是对的）。本片只把 `DataTaskPanel` 那枚**表单区**的纯图标菜单改成文字，其余不动。
5. **没动 `ToolbarIconButton`**：工具条 / 顶带 / 左栏仍是纯图标（本仓既有分工口径，`DialogActionButton` 文件头写着）。
