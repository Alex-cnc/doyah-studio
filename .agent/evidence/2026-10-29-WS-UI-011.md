## 1 由头（这条缺的是什么）

需求三条验收：

| # | 要求 | 本批前状态 |
|---|---|---|
| ① | 三处编辑面同一主题下底色一致（**色值相同**） | **一次都没量过** |
| ② | 切浅色 / 深色与切主题时三处**同步成套**，无一处保留旧色 | **一次都没量过** |
| ③ | 源码里编辑面不出现系统默认底色与硬编码色值 | 早有判据：`Scripts/check-editor-surface-tokens.py`（7 组判据 + `--self-test` **25 例**） |

③ 判的是源码；①② 判的是**绘制出来的像素** —— 令牌是动态色（`NSColor(name:dynamicProvider:)`），
深浅两套值只在**绘制那一刻**按窗口外观求值，所以「三行一模一样的源码」不等于「三个一样的色」。

## 2 量法（本轮立起来的）

`TestsUISnapshot/EditorSurfaceTokenParityProbeTests.swift`：

1. 三面各按**产品里那一处用的同一个视图类型**建视图：`CodeEditorView(tabID:text:language:…)` /
   `SQLEditorView(text:databaseType:diagnostics:tabID:)` / `NotesRichTextEditor(text:spans:controller:)`；
2. 挂进**不上屏的 `NSWindow`**（`NSHostingView`），给确定 size（720×420）与 `NSAppearance`，
   `layoutIfNeeded()` → **跑 0.08s runloop**（SwiftUI 布局下一跳才落，不跑拿到 0×0 退化帧）→ 再布局一次；
3. 在 AppKit 树里找那块 `NSTextView`，**按它的 frame 算取样框**（横向 45…95% × 纵向 45…92%，
   空正文里这一块没有字也没有光标）—— 不写死坐标，版式一改算式跟着变；
4. `cacheDisplay` 落 PNG（`.build/ui-snapshot-state/editor-surface-parity-*.png`），取矩形**众数色**；
5. 与 `theme.palette.content.hex(dark:)` 逐通道比（容差 8；三面互比容差 4）。

## 7 本批发现的两件事（都不在「完成」范围里，如实登记）

1. **包不可逐字节复现**：同一棵干净树连出两次，`Contents/MacOS/DoyahStudio` 的 sha256 分别为
   `b19cdabe…` / `ddb09cd2…`，`du -sk` 两次都是 **99,840 KB**。⇒ 「同一标签必对应同一份二进制」这条
   在**构建侧**不成立：身份只能靠「标签 + 构建时刻 + sha256」那一行区分（R47 立的口径仍然有效，但
   「同标签重出且产物逐字节不变」这一档在本机**测不出来**）。本批未改产品源码，交付内容仍以
   R46 / R47 两批的片 + 本批的判据为准。
2. **`FR-STD` 分族读数行的 🟡 / ⬜ 是陈旧值**：按表格逐行实测 HEAD 为 **✅ 125 / 🟡 69 / ⬜ 19**（合计 213），

   不改历史数字；**等「清号」片一次收口**（同一片上还有 §3/§4/§5 节标题计数与台账第 281 行的占位串）。
