## 5) 这一跳修掉的真缺陷（不只是补判据）

复制 INSERT 原先**一律**写占位表名 `table_name` —— 与第七十二批 CLI 侧认定「看着对、跑不通的 SQL」
同一类：贴进 SQL 编辑器必然指向一张不存在的表。现在按 `QueryTab.sourceTable` 写真实表名与 schema
（`INSERT INTO "public"."orders" …`）；手写 SQL 的结果没有来源表，仍落占位名并**不猜**。
