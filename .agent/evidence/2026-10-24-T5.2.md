# 证据 · T5.2（DDL 预览闸接线）

日期：2026-10-24

## 接线链路

```
TableDesignSheet.previewText                    ← 用户在预览区看到的那份脚本（唯一的「预览事实」）
  → TableDesignSubmission.previewedScript       ← 提交时随表单带上（新增字段）
  → AppState.recordDDLPreview(_:)               ← 装配层记录（previewedDDLScript）
  → AppState.createTable / alterTable           ← 执行前 DDLPreviewGate.decide(script:previewedScript:)
```

## 为什么这么接

- 预览与执行**必须同一份脚本**：历史上「预览拼一份、执行拼另一份」直接造成过每列 `ADD COLUMN` 翻倍（MySQL `Duplicate column name 'id'`，2026-09-25 实测）。所以判据不是「有没有点过预览按钮」，而是**两份脚本逐字相同**。
- 预览后改稿 ⇒ `.previewStale` ⇒ 拒绝，逼迫重新预览（而不是拿旧预览放行新脚本）。
