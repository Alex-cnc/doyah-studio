## 结果与证据

### 1. 新增 Core 两份（纯函数，判据可机械跑）

- `Core/GitDiffRequest.swift`：取值口径收成一个值（`ignoresWhitespace` / `contextLines`），
  `switches` 产出 `-w` / `-U<n>`，`applying(to:)` 把开关**插在 `--` 之前**。
  口径：忽略空白走 git 自己的 `-w`，**不本地过滤文本** —— 本地过滤等于另写一套差异算法。
- `Core/GitDiffPresentation.swift`：长段上下文折成一行（两端各留 `keepContext`，不足 2 行不折）、
  **改动的行永不折**、折叠锚 = `首行号|首行号|条数`（内容寻址）、一页 `pageLimit`（缺省 400）按需渲染、
  `.more(hidden:)` 收尾，`foldCount` / `foldedLineCount` / `hiddenRows` 各自记账。
- `Core/GitUnifiedDiff.defaultMaxLinesPerFile` 4_000 → **50_000**（只兜底病态输入；渲染由呈现层分页）。

### 2. 接线三处

- `App/GitWorktreeProbe.loadDiff(request:)`：参数 = `request.applying(to: base)`，探针里**没有** `-w` / `-U` 字面量。
- `App/GitChangesModel`：`request` / `expandedFolds` / `visiblePages` 三个 `@Published`；
  `setIgnoresWhitespace` / `setContextLines` ⇒ `reloadForRequestChange()`（重取 + 清折清页）；
  `presentation(for:)` / `toggleFold(_:)` / `showMore(file:)`。
- `App/Views/GitChangesPanel.swift`：顶栏「忽略空白」（`Toggle(.checkbox)`）+「上下文 N 行」档位（3/12/40）；
  正文一律走 `model.presentation`（`.hunkHeader` / `.line` / `.fold` / `.more` 四档），
  折行点一下就地展开、末尾「还有 N 行」点一次多一页；忽略空白吃光差异时改用 `gitDiffEmptyAfterWhitespace`。
- 语言表 6 键中英齐：`gitDiffIgnoreWhitespace` / `gitDiffContextLines` / `gitDiffFoldHidden` /
  `gitDiffFoldExpand` / `gitDiffShowMore` / `gitDiffEmptyAfterWhitespace`。

## 顺带修掉的一处真红（第五十七批自己留下的）

`App/AppState.swift` 四处把**带占位符的模板串**交给 Core 做 `String(format:)`
（`durationFormat` / `resultsFormat` / `resultsTruncated` / `redactionFormat`）。
语言表对账判据判 B「实参 0 个、模板有 1 个占位符」是**对的** —— 它看不到那份串是拿去别处填的。
改法不是登记豁免，而是把 `ReceiptLabels` 这四处改成**值格式闭包**
（`{ L(.receiptSeconds, $0) }` / `{ L(.receiptResultsFormat, $0, $1, $2) }` …）：
模板与实参回到同一句，B 不再是假红，A/A′ 也开始真的检查这四句。
`Scripts/format-argument-dispositions.json` 按实测对齐：新增 `$1` / `$2` / `<step>` / `<hidden>` /
`.defaultMaxLinesPerFile` / `moved.deletingLastPathComponent(…)` / `entry.originalURL?.lastPathCompo` 七个形状，
`$0` 2 → 6、`<name>` 11 → 13、`tabs[index].title` 2 → 4、`<count>` 4 → 5，未知实参预算 170 → 188（理由写进台账 note）。
门禁自证两段：少传一个实参 ⇒ 判 B 红；`<hidden>` 处数上限调 0 ⇒ 判 D 红（两段都实测为红后还原）。
