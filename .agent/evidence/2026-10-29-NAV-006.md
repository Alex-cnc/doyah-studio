# 2026-10-29 · R64 · FR-STD-WS-NAV-006（悬停文档与跳转到定义，词法级）

## 本轮做了什么

- `Core/SymbolOutline.swift`（新增）：同文件符号表 + 解析。
  - 声明扫描按语言的**声明关键字表**（`SymbolRules.table`，加语言只动一行）：函数 / 类型 / 变量 / 表 / 别名 / 列。
  - **作用域由内向外**：`{ }` 建作用域森林；引用先在本层找（取引用之前最近的一条，之前没有取本层第一条 —— 先调用后声明），
    找不到才往外走；走到底没有 ⇒ `.notDeclaredInFile`。**兄弟函数里的同名不许借**（需求末栏「不是全文搜一遍同名」）。
  - 字符串 / 注释里的同名不算符号：掩码取 `CodeLexer.protectedSpans`（与折叠、片段同一份），不另写引号识别。
  - SQL：`FROM orders o` 记别名声明（`target = orders`）、`o.total` 说得出「`total` 是 `orders` 的列」；裸列名没有定义就明说查不到。
  - 三档「查不到」分档：`notAnIdentifier` / `protectedRegion` / `notDeclaredInFile` / `noSymbolsForLanguage`。
- `App/Views/SymbolHover.swift`（新增）：**一份接线给两个编辑面**。
  - 悬停 = 系统 tooltip 动态文案（`view(_:stringForToolTip:point:userData:)`），文案在弹出那一刻按鼠标位置解析。
  - ⌘ 点击 = 跳定义；**查不到不吞点击**（交还系统做选词）。
  - 各编辑器只回答「我这份文本按哪种语言建表」：`CodeTextView` → `completionLanguage`，`SQLTextView` → `.sql`。
- `Core/Localization.swift`：+10 键中英齐（六档类别词 / 行标签 / ⌘ 点击提示 / 两档「查不到」）。
- `Tests/SymbolOutlineTests.swift` 21 例 + `Tests/SymbolHoverSourceTests.swift` 4 例。
