# 人工点验清单（macOS · 2026-11-03）

> 来源：台账 `Docs/Doyah产品开发计划任务清单-macOS.md` 里「两列已绿但差人眼/手感」的 17 条。
> 每条点完在这一行打 `[x]`，并把结论（过 / 不过 + 一句话）写在下面 —— 我按它翻账。
> 判据纪律：**跳过不算通过**；不过的要写清「点的是什么、看到的是什么、期望是什么」。

## 一、纯点验（不需要额外环境，约 15 分钟）

- [ ] **1. `WS-UI-005` 命令面板** — `⌘K` 唤起 → 输入 `新建` / `执行` / `格式化` 能看到可搜索的条目 → 回车执行其中一条（如「新建查询」应开一个新页签）。
      期望：面板可搜、可键盘上下、选中项执行生效；Esc 关闭。
- [ ] **2. `WS-UI-006` 标题栏** — 依次点左侧活动栏四个图标（文件 / 数据库 / 智能体 / 设置）。
      期望：窗口标题跟着变（如「Doyah Studio - 工作区 / 数据库 …」），标题栏中间那格搜索框一直在。
- [ ] **3. `WS-UI-008` 主题与字体** — 设置里把主题切「浅色 / 深色 / 跟随系统」三态各看一次；把编辑器字号调大两档。
      期望：配色立刻变、重启后保持；等宽字体在中英文都对齐，行号也跟着变。
- [ ] **4. `WS-UI-014` 对话框按钮** — 打开任意一个 Sheet（如「保存任务」「新建连接」）。
      期望：按钮是**系统文字按钮**（取消为系统取消样式，不是 ✕ 图标）。⚠️ 这条就是你刚帮我抓到的同类缺陷，重点看还有没有别处仍是图标按钮。
- [ ] **5. `WS-TOOL-001` 终端面板** — 底部「终端」页签 → 拖拽分隔条改高矮 → 折叠/展开 → 在里面敲 `ls` + 回车。
      期望：真 shell 有输出；折叠后能展开；多会话页签能切。
- [ ] **6. `WS-EDIT-013` 标头搜索框** — 工作区左上搜索框输入一个词（如 `README`）。
      期望：分「文件名」与「内容」两组、条数对得上；↓↑ 选、回车打开并跳到命中行；底部有「跳过 N 个文件」。
- [ ] **7. `WS-WEB-001` 内嵌浏览器** — 开一个网页页签（或 `page.html`）→ 点其中一条链接 → 下载一个小文件试试。
      期望：页面能加载、链接在当前页签内跳转、下载有进度或提示。
- [ ] **8. `WS-FS-008` 按类别打开** — 依次点开 `.py`、`.md`、`.html`、`.png`。
      期望：前三个进编辑器（`.md` 自动分屏预览、`.html` 进网页页签），图片按预览打开，不误当文本。

## 二、智能体面（9–10 项里挑，约 10 分钟）

- [ ] **9. `AGT-UX-CONV-012` 九个显示开关** — `/` 打开面板 → 把九个开关逐个拨一次 → 退出重启。
      期望：每拨一个界面上立刻有对应变化（流式 / 紧凑 / 思考段 / 时间戳 / 工具进度 / 指示字形 / 长消息预览 / 底栏元数据 / 运行中提交），**重启后保持**。
- [ ] **10. `AGT-UX-CONV-008` 主动通知** — 跑一个长任务（如让它改两个文件），跑起来后把 App 切到后台（`⌘H`）。
      期望：完成时**系统通知真的弹一次**（没授权通知时会静默丢弃，那种情况页面内应有提示条）。
- [ ] **11. `AGT-UX-CONV-009` 求助通道** — 让它做一件需要你配合的事（如「把某个文件改掉」但文件不可写）。
      期望：它明确说「我需要你做一件事：…」，而不是含糊地报错或自己瞎猜。
- [ ] **12. `AGT-TOOL-SYS-002` 子任务委派** — 让它把一个任务拆给子代理并行做（如「并行检查三个文件的问题」）。
      期望：结果汇总回来且**标明来源**（哪一条来自哪个子代理）。
- [ ] **13. `AGT-UX-CONV-001` / `AGT-PLAN-PLAN-001`** — 需要**真模型端点**（`agent.json` 里 `model` 现在是空串）。
      期望：填上端点后，「对话式诊断」能解读一条慢查询、「维护任务编排」能生成一份可执行计划。

## 三、数据库面（4 项，其中 1 项不用点）

- [ ] **14. `DB-META-006` 对象树持续下钻 + 重试** — 连一个连不上的库 → 展开它。
      期望：红字旁有「重试」；点重试后旧红字先消失再重新取；在途时入口消失。
- [ ] **15. `DB-IO-007` Excel 导入** — 用 **Excel 或 Numbers 真实另存**一份 `.xlsx`，走导入向导。
      期望：能读出表头与数据（现有夹具是程序造的，真软件产出没验过）。
- [ ] **16. `DB-IO-002` 整库导出（COPY 路径）** — **不用点**：这是已知限制（驱动里 `CopyOut` 未实现），台账已按「不动 vendor」登记，除非你要改这个决定。

## 四、需要你给条件才能验（不算点验）

- `AGT-UX-CONV-001` / `PLAN-001`：需要**真模型端点**（API key + 端点）。
- `DB-*` 的重试与导入：需要**一个能连的库**（现在有 `192.168.5.26:5432` PG，账号口令待给）。
- `AGT-*` 云端相关（`UX-SYNC-001` / `LINK-EXT-*`）：需要真云端账号。
