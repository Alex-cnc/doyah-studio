# 循环规约（v0.3.0 数据库运维面）· **v2 批量化**

**队列**：`.agent/batches.yaml`（批次）+ `.agent/plan.yaml`（单条任务）；**唯一事实源** = `Docs/Doyah产品开发计划任务清单-macOS.md`。

**为什么要改**（人类主人 2026-11-01 令）：一跳 20 分钟里，全量单测只占 25 秒，其余是每跳重复付一次的
读盘、写证据、跑门禁、提交的手续费 —— 一条活付一次手续费，33 条就付 33 次。改成「一批活付一次」。

## 一跳（tick）的唯一形状

1. 读 `.agent/batches.yaml` + `.agent/plan.yaml` + `.agent/checkpoint.md`；
2. `batch` = `batches.yaml` 里第一个 `status: todo` 的批次（**3–6 条同类项**；上限 6 条或 90 分钟，先到先切）；
3. 一次把这个批次里的条目**一起**做完 —— 同域同构，代码一次改多处、测试写一次；
4. **批末**才跑验证，一条命令链跑完：
   - `swift test`（全量，实测约 25 秒）；
   - `./Scripts/verify-ui-interactions.sh`（29 条探针，一次跑完，**不许每条一跳跑一次**）；
   - 文档门禁：`check-doc-tables` / `check-doc-numbers` / `check-plan-coverage` / `check-status-consistency` / `check-version-scope`；
   - 每条用 `python3 Scripts/ledger-row.py <ID>` 抽查它那一行翻没翻；
5. 落盘（**一份**，不是每条一份）：
   - 台账逐行翻 ✅（实现列与判据列分开翻）；
   - `.agent/evidence/<日期>-<批次号>.md`，**一段式、≤30 行**（见下）；
   - `git commit` 一次，信息写「批次号 + 条目清单 + 读数」；
6. 更新 `checkpoint.md` 的「下一批」，回第 1 步。

## 证据不要再写长文

旧的 135 行/条证据是纯开销（33 条 ≈ 4400 行文档，写它比跑测试贵一个量级）。新格式固定四块：

```markdown
# <批次号> · <日期>
条目：FR-XXX-001 / FR-XXX-002 / …
判据：
$ <可复制命令>
<读数尾部 3–8 行，含 Executed N tests … 0 failures 与探针收尾行>
提交：<sha>
未验证：<没有就写「无」；不写「大概」「应该」>
```

## 四出口（除此之外不许结束一跳）

1. 没有 `todo` 批次 ⇒ 全部完成，写收口；
2. 只剩 `blocked` 且无替代 ⇒ 阻塞退出，写清停在哪、需要什么；
3. 预算耗尽 ⇒ 写检查点，**必须写明下一批 id**；
4. 只有三类允许提问：判据互斥 / 需要授权（越权·花钱·删数据·外发）/ 判据不可判且盘上无可推默认值。

其余一切自行决定，写 `decisions.md` 一行，继续。

## 判据纪律（不变）

- 完成 = 跑命令拿到期望读数；模型自述、截图「看起来对」、空壳探针都不算。
- 新判据要验反例（改坏一处 ⇒ 判红 ⇒ 还原复绿），三段读数进证据文件。
- 实现列与判据列分开翻；界面点不到的，判据可以 ✅、实现留 🟡 并写清差哪个入口。
- 台账行翻 ✅ 必须同时有：可跑的用例/探针 + 实测读数；**跳过不算通过**。
- 改测试条数要同批同步 `Scripts/doc-numbers.json` 与文档里的现状数字。

## 每批收尾

- 一批一片提交，信息写「批次号 + 条目清单 + 判据读数」；推前 `git fetch && git rebase`（同仓常有别的写者）。
- 汇报只给：本批入口条数 → 出口条数 + 下一批 id。**不写「要不要继续」**。

## 判据维护跳的出口（人类主人 2026-11-02 07:55 令 · 主人暂时接触不到循环，由组长代写）

队列空时可以修判据，但**它不是无限工程**，必须有硬出口：

1. **最多再开 2 跳**。到顶就停，不管还剩几个红。
2. 每跳必须在证据里报**净减红数** =（本轮清掉的红）−（本轮新冒出的红）。**连续 2 跳净减 ≤ 0 ⇒ 立即停手**。
3. 剩下的红**必须三分标注**并写进 `checkpoint.md` 一行：
   - `确定性失败` —— 有复现步骤，任何人照做都红；
   - `抖动` —— 同一棵树重跑不复现；
   - `未复现` —— 给不出复现步骤（**不许写成「应该没问题」**）。
4. 三分标注写完 ⇒ **当跳立刻转下一版**（v0.4.0，见 `.agent/next-version.md`），不许再开维护跳；除非人类主人新令。
5. 判据维护跳**不产出需求进度**，所以它不许挤占版本推进：一个版本收口后，维护跳总预算 ≤ 3 跳（含已开的）。
