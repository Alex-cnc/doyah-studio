## 附加：数据库（alpha 1.0 的功能）回归 —— **只验"没被改坏"**

> 为什么 2.x 的清单里要放这一节：2.x 的改动面里有编辑面、保存、检索、格式化这些**和数据库共用底座**
> 的东西（主题令牌、命令面板、IPC 契约、外观持久化）。它们被改坏的话，**数据库那一块会跟着坏**。
> 所以装 2.x 的包时，顺手把 1.0 的**关键几条**再走一遍即可，**不必重跑 1.0 的全部 22 条**。

| # | 事项 | 怎么点 | 预期（可判定） | 结果 |
|---|---|---|---|---|

> **本版界面按老板给的两张 macOS 封面图改过**（工作区 / 数据库）：底部面板（问题·输出·终端·调试控制台）、Home 页三栏（最近文件 / 最近工作区 / 连接）、数据库左栏（连接列表分组 + 对象树两种视图）、SQL 工具条（库下拉 + 清空）+ 查询页签、标题栏搜索接全局搜索。**对了图的地方说对，不对的地方请直接指出来。**

**本版已做的一条（与「形态」有关，单列出来）**：**代码格式化（2.6）** 按人类主人 2026-10-02 定案（「优先外部，如无联网则用内置」）实现 —— **外部工具优先；没有（或不可用）⇒ 回退内置并如实说明**。核对方式见上面第 23~25 条。

**本版明确不做**（不是缺陷，是范围；出包时按实际交付面逐条核对）：

- **权限 / 属性编辑**（自用口径，计划已定"不做"）。
- **用户自定义主题编辑器**（计划已定"不做"）。
- **插件市场 / 远端同步**（计划已定"不做"）。
- **内置终端（2.7）**：领域层三笔已落，但**ConPTY 落地卡住**（实测"子进程不执行命令"，已回退不留残缺代码）⇒ **本版不给终端入口**，等拍板后再做。
- **智能体接面（2.9 的一半）** 与检索里的「笔记」那一类：笔记属 3.x，且计划 3.7 已定"Windows 版 Notes 当前不在投入面"。
